Relocate Order Stock
Production
POST
https://api.salla.dev/admin/v2/orders/{order_id}/inventory/relocate
Try it
Last modified:
6 days ago
This endpoint allows you to update order stock location associated with a spesific order.
Scopes
orders.read_write - Orders Read & Write
Request
Authorization
Add the parameter Authorization to Headers，whose value is to concatenate the Token after the Bearer.
Example:
Authorization: Bearer ********************
Path Params
Generate Code
order_id
integer 
required
Unique identifier associated with an order. Get a list of order id here
Example:
3155923424
Body Params
application/json
Generate Code
source
number 
required
Allows specifying the source branch from which stock is deducted.
destination
number 
required
Allows specifying the source destination from which stock is is added.
items
array [object] 
optional
A list of order items with their respective quantities to be relocated, it is not mandatory, it can be used if there is some items or quantities to be reallocated.
id
number 
required
The unique identifier for the item being relocated. This is typically a reference to the order item
quantity
integer 
required
The number of units of the item to be relocated. This must be a positive integer.
Example
{
    "source": 1923546554,
    "destination": 495787195,
    "items": [
        {
            "id": 123413414,
            "quantity": 2
        }
    ]
}
