External Orders
Production
POST
https://api.salla.dev/admin/v2/orders/external
Try it
Last modified:
6 days ago
This endpoint allows you to create external orders, that happened out of Salla platform.
Scopes
orders.read_write - Orders Read & Write
Request
Authorization
Add the parameter Authorization to Headers，whose value is to concatenate the Token after the Bearer.
Example:
Authorization: Bearer ********************
Body Params
application/json
Generate Code
external_order_id
string 
required
Unique identifier for the order from the external system. Must be unique - duplicate IDs will be rejected.
date
string 
optional
Order creation date in ISO 8601 format (e.g., '2024-01-15T10:30:00Z'). Used for backdating imported orders.
source
string 
optional
Supported order sources: shopify, woocommerce, wix, trendyol, amazon, prestashop, magento, sitecore, zid, other (default).
status_name
string 
optional
Name of the order status (e.g., 'completed', 'pending'). Can be a native status or custom status name.
currency
string 
required
Currency code for the order (e.g., 'SAR', 'USD'). Used for currency exchange calculations.
exchange_currency_rate
number 
optional
Exchange rate for the order currency. If not provided, the system will automatically calculate the rate based on current exchange rates.
subtotal
number 
required
Order subtotal amount before tax, shipping, and discounts.
tax
object 
required
Tax information for the entire order.
rate
number 
optional
Tax rate percentage (e.g., 15 for 15%). If not provided but value is set, rate is calculated automatically.
value
number 
required
Absolute tax amount in the order currency.
customer
object 
required
Customer information for the order.
id
integer 
optional
Existing customer ID in the Salla system. Required to associate order with a customer.Required if not guest.
name
string 
optional
Customer Name, in case customer does not exist.
mobile
string 
optional
Customer's mobile phone number.
email
string 
optional
Customer Email, in case customer does not exist.
is_guest
boolean 
optional
Whether the customer is a guest (not registered).
products
array [object] 
required
List of products/items in the order.
name
string 
required
Product name/title to display in the order.
price
number 
required
Unit price per item in the order currency.
cost_price
number 
optional
Cost price for profit margin calculations.
sku
string 
optional
Stock Keeping Unit code for inventory tracking.
weight
number 
optional
Product weight for shipping calculations.
quantity
integer 
optional
Number of units ordered. Defaults to 1 if not provided.
weight_type
string 
optional
Unit of weight measurement (e.g., 'kg', 'g', 'lb'). Uses store default if not specified.
require_shipping
boolean 
optional
Whether this product requires physical shipping. Defaults to true.
product_type
string 
optional
Type of product (e.g., 'product', 'digital', 'codes'). Affects shipping and fulfillment.
mpn
string 
optional
Manufacturer Part Number for product identification.
gtin
string 
optional
Global Trade Item Number (barcode) such as UPC, EAN, or ISBN.
product_discount
number 
optional
Discount amount applied to this specific product.
thumbnail
string 
optional
URL of the product thumbnail image.
tax
object 
required
Tax information for this specific product.
discounts
object 
optional
Discount/coupon information applied to the order.
code
string 
required
External reference code for the discount/coupon.
amount
number 
required
Discount amount applied to products.
shipping_amount
number 
required
Discount amount applied to shipping. Must equal shipping_cost for free shipping.
payment
object 
required
Payment details for the order.
status
string 
required
Payment status. Allowed values: 'paid' or 'pending_payment'.
method
string 
required
"Payment method used. Only 'cod' (Cash on Delivery) or 'external_epayment' are accepted. Required when status is 'paid'."
gateway
object 
required
Custom payment gateway information for tracking purposes.
cash_on_delivery
object 
required
Cash on delivery fee details.
receiver
object 
required
Shipping recipient information (person receiving the order).
name
string 
required
Full name of the receiver. Must be 4-200 characters.
phone
string 
required
Phone number of the receiver (validated against country_code).
country_code
string 
required
ISO country code for phone validation (e.g., 'SA', 'AE').
email
string 
required
Email address of the receiver for notifications.
notify
integer 
required
Whether to send order notifications to the receiver (0 or 1).
delivery_method
string 
optional
Delivery method for the order. Values: 'shipping' (home delivery) or 'pickup' (store pickup).
courier_id
integer 
optional
ID of the shipping company/courier. Must be a valid enabled courier for the store.
shipping_cost
number 
optional
Shipping cost amount. Set to 0 for free shipping.
ship_to
object 
optional
Shipping destination address details.
country
integer 
required
Country ID from Salla's country list. Required if shippable.
city
integer 
required
City ID from Salla's city list. Required if shippable.
block
string 
optional
Block/area identifier within the address.
district
integer 
optional
District ID from Salla's district list.
street_number
string 
optional
Street number of the delivery address.
address
string 
optional
Primary address line/location description.
address_line
string 
optional
Additional address line (stored as additional_number).
postal_code
string 
optional
Postal/ZIP code for the delivery address.
geo_coordinates
object 
optional
Geographic coordinates for precise delivery location.
house_desc
string 
optional
Building/house description or number.
branch_id
integer 
optional
Store branch ID for pickup orders or to specify the shipping origin branch.
