Create Order History
Production
POST
https://api.salla.dev/admin/v2/orders/{order_id}/histories
Try it
Last modified:
5 days ago
This endpoint allows you to append a note to the Order History, by passing the order_id as a path parameter.
Scopes
orders.read_write - Orders Read & Write
Request
Authorization
Add the parameter Authorization to Headers，whose value is to concatenate the Token after the Bearer.
Example:
Authorization: Bearer ********************
