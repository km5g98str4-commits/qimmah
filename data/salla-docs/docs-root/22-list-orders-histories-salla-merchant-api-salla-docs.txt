List Order Histories
Production
GET
https://api.salla.dev/admin/v2/orders/{order_id}/histories
Try it
Last modified:
5 days ago
This endpoint allows you to return the order history of previous and current order statuses for a specific order by passing the order_id as a path parameter.
Request
Authorization
Add the parameter Authorization to Headers，whose value is to concatenate the Token after the Bearer.
Example:
Authorization: Bearer ********************
Path Params

integer 
required
Unique identification number assigend to an order. Get a list of Order IDs from here.
