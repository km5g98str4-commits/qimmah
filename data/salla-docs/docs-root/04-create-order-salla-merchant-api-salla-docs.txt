Create Order

POST

This endpoint allows you to create an order related to your store. It supports both standard one-time purchases and subscription-based orders.
Scopes
orders.read_write - Orders Read & Write
Request
Authorization
Add the parameter Authorization to Headers，whose value is to concatenate the Token after the Bearer.
Example:
Authorization: Bearer ********************
