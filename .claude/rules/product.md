# قواعد المنتج

## المبدأ
Gym OS قالب تجاري قابل للبيع. كل قرار يخدم: **وضوح القيمة + سهولة التخصيص + جاهزية البيع**.

## الجمهور
أفراد متمرّنون، مدرّبون/صالات، ومشترو قوالب في السوق السعودي/الخليجي.

## قواعد المحتوى
- كل محتوى قابل للتخصيص في `config/` أو `data/` — لا hardcoding.
- البيانات الافتراضية واقعية ومحترمة (أوزان، سعرات، جرعات منطقية) لأنها تمثّل جودة المنتج.
- لا ادعاءات طبية. المكملات/الأدوية للعرض فقط مع تنويه عند الحاجة.

## نطاق v1.0
- Frontend فقط، بلا backend/مصادقة/تخزين فعلي.
- لا تُضِف ميزات خارج القائمة المعتمدة دون طلب صريح.
- التحسينات تبقى ضمن «جودة» لا «ميزات جديدة».

## أولويات القرار عند التعارض
1. وضوح القيمة للمشتري.
2. سهولة التخصيص.
3. الأناقة البصرية.
4. التوسّع المستقبلي (دون تعقيد الحاضر).

## معايير «جاهز للبيع»
