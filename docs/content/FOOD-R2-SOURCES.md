# Food R2 sourcing method

All 60 entries are generic-first and marked **«تقديري»**. They are planning estimates, not
restaurant claims.

| Category | Estimation method | Sanity range |
|---|---|---|
| Broast / strips | cooked chicken portion + breading oil uptake + measured sides | 150–950 kcal |
| Shawarma | cooked meat yield + bread + garlic/tahini; plates add rice/fries | 250–850 kcal |
| Local burgers | patty/chicken + bun + cheese/sauce; meals add fries/drink | 250–950 kcal |
| Mandi/madhbi/kabsa | cooked rice + quarter/half chicken or lamb + visible fat | 350–1,050 kcal |
| Karak/coffee | drink volume + milk/sugar recipe; black coffee near zero | 0–350 kcal |
| Bakery | product weight + pastry/bread base + filling yield | 180–500 kcal |

The permanent proof checks duplicate IDs/names against the full database, required estimate
labels, category coverage, macro/energy density, and 4/4/9 consistency.
