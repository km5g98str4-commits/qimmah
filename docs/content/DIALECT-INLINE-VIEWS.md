# جرد سلاسل الواجهات — تحويل اللهجة (لتنفيذ Codex)

> **لا تعدّل هذه الملفات في موجة `content/dialect-copy-v1`** — هذا جرد فقط.
> المرجع الرسمي للنبرة والقاموس: `docs/content/DIALECT-TONE-GUIDE.md`.
> أرقام الأسطر كما في فرع `content/dialect-copy-v1` (الأساس 19ec00a) — قد تنزاح بعد أي تعديل.

## القواعد المختصرة للمنفّذ

1. حوّل **الجُمل** فقط؛ التسميات القصيرة المحايدة (رجوع، حفظ، إلغاء، اختياري…) تبقى.
2. تسميات الأزرار المفردة مثل «لاحقًا» مقبولة كما هي (قرار الدليل).
3. `aria-label` تبقى فصحى محايدة واضحة إذا كانت وصفًا تقنيًا (مثال: «تأكيد تجاهل التمرين»).
4. محوّطات الأمانة (honesty qualifiers) تتغيّر صياغةً لا دلالةً — انظر جدول الأمانة في الدليل.
5. الإنجليزية المقابلة في `t('…', '…')` غالبًا casual أصلًا — عدّلها فقط إن كانت رسمية.

## ملاحظات إلزامية للتنفيذ

- **الموجات غير المدموجة**: فروع مثل `design/v21-promotion` وموجات الميزات غير المدموجة تحمل
  سلاسل واجهات خاصة بها لم يشملها هذا الجرد — **يجب إعادة تمرير اللهجة عند التكامل** على أي
  سلسلة جديدة تدخل من تلك الفروع، بنفس دليل النبرة.
- بقية السلاسل العربية في `src/views/`/`src/components/` (~380 سلسلة) إمّا محايدة قصيرة
  (تبقى) أو لهجة أصلًا؛ الجدول أعلاه يحصر ما فيه فصحى ظاهرة تحتاج تحويلًا.
- بعد التنفيذ: `npm run typecheck && npm run lint && npm run build` + تحديث أي توقّع نصي
  في `scripts/` انكسر (بلا إضعاف الفحص).
