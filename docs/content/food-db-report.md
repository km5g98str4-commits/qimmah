المُدقِّق: `scripts/food-db-validate.mjs` — يجمّع `src/data/foodItems.ts` (يشمل الأطباق السعودية) عبر esbuild
ويفحص كل صنف. التشغيل:

```bash
node scripts/food-db-validate.mjs           # تقرير كامل (ERROR ⇒ خروج 1)
node scripts/food-db-validate.mjs --json     # مخرجات آلية
node scripts/food-db-validate.mjs --strict    # يفشل أيضًا على التحذيرات
```

## ما يفحصه
| الرمز | المستوى | الفحص |
|---|---|---|
| `MISSING_STR` / `MISSING_NUM` | ERROR | حقول نصّية/رقمية إلزامية مفقودة أو غير صالحة |
| `NEGATIVE` / `BAD_FIBER` | ERROR | قيمة سالبة أو ألياف غير صالحة |
| `RANGE_MACRO` / `RANGE_SUM` / `RANGE_KCAL` | ERROR | ماكرو > 100غ/100غ، مجموع الماكروز > 105غ/100غ، أو كثافة > 9.1 سعرة/غ |
| `DUP_ID` | ERROR | معرّف مكرّر |
| `KCAL_449` | WARN | السعرات خارج نطاق قاعدة 4/4/9 ±15% — **واعٍ بالألياف** (Atwater: الألياف ≈ 2 سعرة/غ) لتجنّب الإيجابيات الكاذبة في الخضار عالية الألياف؛ ويتجاهل ضجيج التقريب دون 30 سعرة |
| `DUP_NAME_AR` / `DUP_NAME_EN` | WARN | اسم مكرّر (مطبّع: قصّ، دمج فراغات، توحيد الألف/الياء/التاء، إزالة التطويل) — مرشّح لإزالة التكرار |
