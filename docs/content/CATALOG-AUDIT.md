# Exercise Catalog Audit — Qimmah (content/catalog-audit-seed)

تدقيق كتالوج التمارين قبل الإطلاق. الأداة: `node scripts/run-catalog-media-proof.mjs`
(محلي، بوّابة) و `CATALOG_MEDIA_REMOTE=1 node scripts/run-catalog-media-proof.mjs` (+ فحص HTTP).

## أين يعيش الكتالوج

| المصدر | المحتوى |
|---|---|
| `src/data/exercises.ts` | ١٨١ تمرينًا: `id · nameAr · nameEn · primaryMuscle (enum) · equipment · defaultReps/Rest · notesAr · techniqueTipsAr · safetyNotesAr · videoUrl` |
| `src/data/exerciseMedia.ts` | وسائط ١٢٥ تمرينًا: إطارا بداية/نهاية محلّيان + بديلان بعيدان (free-exercise-db, Unlicense) |
| `src/data/machineImages.ts` | صور ٢٤ جهازًا محلّية |
| `src/data/machineHowTo.ts` | خطوات استخدام الأجهزة (عربي) |
| `src/data/workoutTemplates.ts` | البرامج الأربعة المعتمدة (أجهزة فقط) |

## ١) الوسائط — HTTP + محلّي

| الفئة | العدد | نجح | فشل/مكسور |
|---|---|---|---|
| إطارات تمارين محلّية (public/exercise-images) | ٢٥٠ ملفًا | ٢٥٠ | ٠ |
| صور أجهزة محلّية (public/exercise-machine-images) | ٢٤ ملفًا | ٢٤ | ٠ |
| روابط بعيدة (raw.githubusercontent · HTTP HEAD) | ٢٥٠ رابطًا | ٢٥٠ (200 · image/\*) | ٠ |

**النتيجة: صفر وسائط مكسورة** — كل الأصول التي يشحنها التطبيق سليمة (JPEG/PNG/WebP/GIF صالحة،
حجم>0، توقيع صحيح)، وكل رابط مصدر إعادة التوليد حيّ. لا حاجة لإدخالات في `BROKEN-MEDIA.md`.

ملاحظتان (غير حاجبتين — موثّقتان في `BROKEN-MEDIA.md`):
- ٤ أجهزة في البرامج بلا صورة جهاز → تُعرض على **البديل الأنيق** (تصميم مقصود، ليست مكسورة).
- ٢٠ صورة جهاز بامتداد `.jpg` بينما الصيغة الفعلية PNG/WebP/GIF → تُعرض بلا مشكلة (المتصفّح
  وWKWebView يستنشقان البايتات)؛ تنظيف امتداد اختياري لاحقًا.

## ٢) النبرة والاتساق (PDF §02)

- **لا لهجة خليجية** في أسماء/إرشادات التمارين — مسح `وش|الحين|تبي|كذا` نظيف (الإصابات
  الظاهرة في `foodItems`/`saudiFoods` أسماء أطباق سعودية حقيقية: فتوش/مقشوش/برنقوش/محشوش، لا سلانغ).
- **مصطلح موحّد:** العضلة حقل enum مُقيَّد (`Muscle`) ⇒ نفس العضلة = نفس الكلمة في كل مكان.
- **لا نصوص فارغة/بديلة:** صفر `nameAr/nameEn` فارغ، صفر `TODO/placeholder/lorem`.
- **الإجراء:** لا تعديل مطلوب — الكتالوج نظيف أصلًا (لا نُحدث تغييرًا وهميًا).

## ٣) التغطية — البرامج الأربعة

| البرنامج | الأيام | معرّفات التمارين | كلها في `exercises.ts`؟ | حقول ناقصة |
|---|---|---|---|---|
| علوي / سفلي (Upper/Lower) | ٤ | ✓ | ✅ | لا |
| جسم كامل (Full Body) | ٣ | ✓ | ✅ | لا |
| تقسيمة أرنولد (Arnold) | ٦ | ✓ | ✅ | لا |
| دفع/سحب/أرجل (PPL ٣ و٦) | ٣/٦ | ✓ | ✅ | لا |

**١٦ معرّفًا فريدًا** تستخدمها البرامج الأربعة — **كلها موجودة في الكتالوج، صفر يتيم، صفر فجوة**
(`comm -23 program_ids exercise_ids` فارغ). كل معرّف له `nameAr/muscle/equipment` كامل.

## الخلاصة

الكتالوج **جاهز للإطلاق**: وسائط ١٠٠٪ سليمة (٥٢٤ فحصًا)، تغطية ١٠٠٪، نبرة نظيفة. الإثبات
الحتمي: `scripts/catalog-media-proof.ts` (بوّابة محلّية + HTTP اختياري).
