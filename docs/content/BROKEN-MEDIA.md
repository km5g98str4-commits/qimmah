# Broken Media — Qimmah catalog

المصدر: `node scripts/run-catalog-media-proof.mjs` (محلي) و
`CATALOG_MEDIA_REMOTE=1 node scripts/run-catalog-media-proof.mjs` (+ HTTP).

## وسائط مكسورة (تحتاج إصلاحًا)

**لا شيء.** ٢٥٠ إطار تمرين محلّي + ٢٤ صورة جهاز محلّية + ٢٥٠ رابطًا بعيدًا — كلها سليمة
(الحالة 200، نوع `image/*`، حجم>0، توقيع صورة صحيح). لا مرجع مكسور، لا ملف مفقود.

## فجوات موثّقة (غير حاجبة — ليست مكسورة)

### أ) أجهزة برامج بلا صورة جهاز (بديل أنيق مقصود)
هذه الأجهزة تظهر في البرامج المعتمدة لكن لا تملك لقطة جهاز؛ يعرضها التطبيق على البديل
الأنيق (بلا صورة وزن حرّ خاطئة) — سلوك مقصود موثّق في `machineImages.ts`، لا يُعدّ كسرًا.

- `incline-chest-press-machine`
- `lat-pulldown-machine`
- `leg-extension-machine`
- `leg-press-machine`

الإصلاح المستقبلي (خارج نطاق هذا التغيير): جلب صورة الجهاز الحقيقية عبر
`scripts/p12-fetch-machine-images.mjs` ثم إضافتها لخريطة `machineImages.ts`.

### ب) امتداد ملف لا يطابق الصيغة الفعلية (تجميلي)
٢٠ صورة جهاز بامتداد `.jpg` بينما البايتات PNG/WebP/GIF. تُعرض بلا مشكلة (استنشاق
المتصفّح/WKWebView). تنظيف الامتداد + تحديث الخريطة تحسين اختياري، ليس عطلًا.

القائمة الكاملة تُطبع عند تشغيل الإثبات المحلّي (قسم «امتداد لا يطابق الصيغة الفعلية»).
