## مصفوفة الطبقات B (Feature priority — لكل شاشة نقطة تير)
- **● Core v1** — الحلقة الصادقة الكاملة، قابلة للشحن وحدها offline-safe: Auth+Onboarding→خطة · Today (كل سياقاته) · تمرين مباشر/تركيز/راحة/PR/إنهاء+ملخّص · تسجيل offline-first + تأكيد الخمول والإنهاء · تغذية/كمية/ترطيب · تقدّم/خطوات/وزن · مركز الأذونات والخصوصية والوصول وحالة المزامنة · كل شاشات حالات النظام.
- **● v1.1** — ثقة وعمق فوق الحلقة: تسجيل التعافي وتوصيته · إحماء ذكي/استبدال/يد واحدة · وجبة بعد التمرين وتذكير الترطيب · تقدّم القوّة/القياسات/الرسوم · عودة بعد الانقطاع · آبل هيلث/الوضع الليلي التلقائي.
- **● Later** — الذكاء والمتعة بعد توفّر بيانات حقيقية: رفيق AI ومحادثته · اقتراحات AI لتغيير/تطوير الخطة · طبقة الصوت/إعادة العرض · الإنجازات/التحدّيات/ملخّص الأسبوع · سجلّ التعافي/الباركود · Live Activity.
- **● Research** — إثبات القيمة والأمان أولًا: اقتراح حسب الطقس · نظام الأفاتار · صوت on-device مقابل السحابة · عتبات ثقة استدلال التخفيف.

## قاعدة المنتج الأساسية D — «اقترح، لا تُغيّر»
**يتطلّب تأكيدًا دائمًا (لا فعل صامت):** تغيير/تطوير الخطة (اعرض القديم مقابل الجديد) · حفظ جلسة
خاملة/مقطوعة · **إنهاء التمرين — دائمًا اسأل «هل انتهيت؟»** · استبدال تمرين · أسابيع التخفيف ·
نتيجة أمر صوتي (تأكيد مرئي + تراجع) · طلب إذن جديد (اشرح الفائدة أولًا) · تطبيق توصية AI على الخطة.
**يجوز تلقائيًا (قابل للعكس والضبط):** اتباع مظهر النظام · حفظ محلي لكل set لحظيًا · إبقاء الشاشة
مضيئة أثناء الـset · تذكير ترطيب اختياري · حركات الدخول/المؤشّر/التعبئة · استعادة تمرين نشط بعد
إنهاء التطبيق · مزامنة خلفية عند عودة الاتصال · توليد (لا تطبيق) مرشّحات التحدّيات.

## أساس Momentum v3 (القسم E)
**E1 · الألوان الدلالية:** Warm Sand `#EDE8E0` (سطح فاتح) · Graphite `#16140F` (تمرين/تركيز) ·
Ember `#F0512A` (الفعل الأساسي) · Ember Lift `#FF6A3D` (تدرّج) · Green `#1F9D57` (نجاح) ·
Blue `#2A6CE0` (وزن/اتجاهات/رابط) · Teal `#159AA0` (ترطيب/تعافٍ) · Amber `#D99400` (انتباه/تقدير) ·
Red `#D23B2E` (تدمير/تحذير حقيقي فقط) · Ink `#2A251E` · Muted `#8A8276` · Line `#E4DED4`.
**E2 · الخطوط:** Readex Pro (لاتيني) · IBM Plex Sans Arabic (عربي) · JetBrains Mono (أرقام) —
سلّم 8 درجات (display 44 → caption 12).
**E3 · التنقّل السفلي (5، RTL افتراضًا):** اليوم · التمارين · **＋تسجيل** (مرفوع) · التغذية · التقدّم.
الملف/الإعدادات في الترويسة لا كتبويب سادس. ارتفاع 56pt + safe-area؛ كل هدف ≥ 44pt.
**E4 · مسافات/زوايا/ارتفاع:** أساس 4pt · هامش شاشة 16pt · زوايا (control 12–14 · card 20 · sheet 24 · pill 999).
**E5 · الحركة:** لكل حركة وظيفة؛ easing `cubic-bezier(.4,0,.2,1)`؛ enter 240 · exit 180 · micro 120 ·
احتفال ≤900ms؛ لكل حركة بديل reduced-motion ولكل haptic توثيق.

## الأذونات ومصادر البيانات (القسم C — مبدأ عند-الحاجة)
لا إذن يُطلب قبل ظهور فائدته على الشاشة. الخطوات/الوزن ← Apple Health (وإلا يدوي + «غير متصل») ·
**معدّل القلب ← ساعة مقترنة، وإلا «معدّل القلب غير متوفّر» — لا رقم مُختلَق** · الإشعارات ← بعد جهوزية
الخطة · الصوت ← أول ضغط (مع مقابل زرّي دائم) · الطقس ← موقع أو مدينة يدوية · المزامنة/AI ← offline-first.
