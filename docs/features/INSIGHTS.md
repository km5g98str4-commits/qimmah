# محرّك الرؤى الأسبوعية — Insights Engine

يحوّل السجلّات الخام إلى الملخّص الأسبوعي الصادق الذي يَعِد به التصميم (PDF §05): رؤى مُحوَّطة، تقديرات مُعلَّمة،
وامتناع صريح تحت العتبة. **محلي بالكامل، نقيّ، قابل للاختبار.**

## المعمارية (نواة نقيّة + مُهايئ)
```
src/lib/insights/
  types.ts            الأنواع (InsightInput, MetricsBundle, InsightCard, WeeklyInsights)
  metrics.ts   [نقيّ]  المقاييس السبعة + رياضيات الميل/التنعيم/الثبات + العتبات
  generate.ts  [نقيّ]  مولّد البطاقات: ≤3 مرتّبة، جملة مُحوَّطة + فعل + وجهة، أو امتناع
  readers.ts   [مُهايئ] يجمع InsightInput من المتاجر الحقيقية (impure؛ الملف الوحيد الذي يلمسها)
  index.ts            الواجهة: buildWeeklyInsights() (حيّ) · buildInsightsFromInput() (نقيّ للاختبار)
  InsightCardsView.tsx طبقة العرض (تقديمية): بطاقات AA/RTL/reduced-motion
```
النواة لا تلمس المتاجر إطلاقًا — كل الحساب فوق `InsightInput` المحقون، فكل شيء يُختبر بمُدخلات صناعية.

## المقاييس السبعة (على المتاجر الحقيقية)
| المقياس | المصدر | العتبة (تحتها → امتناع) |
|---|---|---|
| حجم التدريب الأسبوعي + Δ عن الأسبوع الماضي | جلسات مكتملة (Σ وزن×تكرار) | ≥1 جلسة في نافذة أسبوعين |
| توزيع العضلات مقابل الخطة | العضلة الأساسية لكل تمرين → مجموعة | ≥2 جلسة هذا الأسبوع |
| الالتزام % (مخطّط مقابل مُنجَز) + متوسّط 4 أسابيع | أيام الجلسات مقابل `workoutPlan.days.length` | خطة أيام معلومة + ≥1 جلسة |
| اتجاه الوزن: تنعيم 7 أيام + ميل مربّعات صغرى + كشف ثبات | قياسات `weightKg` | ≥4 نقاط تمتدّ ≥14 يومًا |
| نسبة إصابة هدف البروتين (آخر 7 أيام) | `nutritionLogs.loggedFood.protein` مقابل `targetProtein` | ≥3 أيام مُسجّلة + هدف > 0 |
| صحّة السلسلة (أيام متتالية + أسابيع متّسقة) | تواريخ الجلسات | ≥1 جلسة |
| القرب من رقم قياسي («قريب من رقم قياسي في X») | أعلى مجموعة حديثة مقابل `bestWeight` | مجموعة ضمن 2.5–6% تحت الأفضل |

**رياضيات الوزن:** `rollingSmooth` (نافذة 7 أيام) ثم `linregSlopePerDay` (مربّعات صغرى) × 7 = كجم/أسبوع.
الثبات = مدى ≥3 أسابيع والنطاق ضمن ±0.6كجم. الميل يُعلَّم دائمًا «تقديري».

## قواعد الصدق (PDF §05 — غير قابلة للتفاوض)
- **تحويط:** كل استنتاج «يبدو أن…»، لا حكم قاطع.
- **تقدير:** التقديرات تحمل «~» و«تقديري» (الميل، Δ الحجم).
- **امتناع:** تحت العتبة، يمتنع المقياس (`status:'abstain'`) ولا يخمّن؛ وإن امتنعت كل المقاييس → بطاقة واحدة
  «نحتاج المزيد من البيانات — واصل التسجيل» بفعل ووجهة.
- **قِس/سجّل للقديم:** آخر قياس وزن > 9 أيام ⇒ `stale` ⇒ بطاقة «قِس وزنك».
- **لا إحصاءة ميّتة:** كل بطاقة = جملة + فعل أمر + وجهة (`progress/nutrition/workout/setup`).

## البطاقات
`generateCards` يُنتج ≤3 بطاقات مرتّبة بالأولوية (الوزن/PR أعلى من الالتزام/البروتين أعلى من الحجم/السلسلة).
حتميّة: نفس المدخل ⇒ نفس الترتيب.

## التكامل مع الواجهة
- **ProgressV2 (الملخّص):** قسم «رؤى الأسبوع» يستهلك `buildWeeklyInsights(lang)` ويعرض البطاقات المرتّبة.
- **TodayV2 (سطح خفيف):** بطاقة «رؤى الأسبوع» واحدة (أعلى رؤية) بين «مسار اليوم» والاقتراحات.
- وصولية: تباين AA (نصّ ink-900 ~19:1، الفعل primary-c ~5.7:1)، RTL منطقي، `motion-reduce`، أزرار أصلية، `aria-label`.

## الاختبار
`node scripts/run-insights-proof.mjs` — 27 فحصًا (esbuild + localStorage مُحاكى):
تنشيف/تضخيم/ثبات/بيانات-غير-كافية/غياب-متاجر، صحّة الامتناع، الميل مقابل حساب يدوي، حتميّة الترتيب (≤3)،
وعزل مستخدمَين (بيانات A لا تتسرّب إلى B بعد المسح). لقطات المراجع: `scripts/insights-shot/` (harness معزول).
