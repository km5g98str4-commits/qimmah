# QA record — موقع قِمّة التسويقي

سجلّ تحقّق موجز للموقع الثابت (`site/`) — للرجوع إليه عند تقديم التطبيق إلى App Store.
كل النتائج أدناه مأخوذة من فحص فعلي على الملفات المنشورة.

## 1) صفر طلبات خارجية
تحميل أي صفحة يُصدر طلبات **من نفس النطاق فقط**: HTML، `site.css`، `favicon.svg`،
وست خطوط woff2 مُستضافة ذاتيًا. لا CDN، لا Google Fonts، لا تحليلات، لا أُطر.
`og-image.png` و`apple-touch-icon.png` لا يُطلبان عند التحميل (وسم مشاركة / إضافة للشاشة فقط).

## 2) سياسة أمان المحتوى (CSP) — مُتحقَّق منها حيًّا
طُبّقت ترويسة `_headers` الفعلية على خادم اختبار، وحُمّلت الصفحات تحتها:

```
default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline';
img-src 'self' data:; font-src 'self'; connect-src 'self'; object-src 'none';
base-uri 'self'; form-action 'self'; frame-ancestors 'none'; upgrade-insecure-requests
```

- `index.html` (به JSON-LD + أنماط `style=""`) → **صفر مخالفات CSP** في الـ console.
- `privacy.html` (به كتلة `<style>` مضمّنة) → **صفر مخالفات**؛ تأكّدنا أن التنسيق طُبّق فعلًا
  (خط IBM Plex Sans Arabic، حدّ العنوان الإمبري 4px، خلفية الورق) — لا حجب صامت.
- `'unsafe-inline'` ممنوح للأنماط فقط؛ `script-src` يبقى `'self'` (لا سكربت مضمّن تنفيذي؛
  JSON-LD كتلة بيانات لا تُنفَّذ). `frame-ancestors 'none'` يمنع التأطير (clickjacking).

## 4) الاستجابة وإمكانية الوصول
- 320 → 1440px بلا تمرير أفقي (تحقّق: `scrollWidth == innerWidth`).
- معالم دلالية: `header`/`main`/`footer`/`nav`، عنوان `h1` واحد لكل صفحة، رابط تخطٍّ.
- RTL: `lang="ar" dir="rtl"`، خصائص منطقية (`border-inline-start`, `padding-inline`).
- `prefers-reduced-motion` محترم؛ حالات تركيز مرئية.
- صفر أخطاء console على كل الصفحات.

## 5) بوابة المستودع
`site/` خارج رسم بناء Vite تمامًا؛ التعديلات في `site/**` + `docs/site/**` فقط.
شيفرة التطبيق **لم تُمَس** — typecheck / lint (`--max-warnings 0`) / build / 92 فحصًا (31+28+33) **خضراء**.
