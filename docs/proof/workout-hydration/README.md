من الواجهة الحقيقية (Playwright): يبدأ جلسة تمرين، يُرجِع بدايتها ٢٥ دقيقة للخلف فيصبح تذكير الـ٢٠ دقيقة مستحقًّا.

## مطابقة معايير DONE
1. **تلقين داخل الجلسة النشطة**: بطاقة تيل أعلى الشاشة النشطة، تظهر كل فترة يضبطها المستخدم (افتراضي ٢٠ د). **غير مُقتحِمة** — لا تغطّي محرّر المجموعة ولا زر «أنهِ المجموعة» (ظاهران أسفلها في اللقطة)، ولا تقطع مؤقّت الراحة (تُعرض فوق التفرّع، لا داخل RestPanel).
2. **تحكّم المستخدم**: التكرار (شرائح ١٥/٢٠/٣٠/٤٥/٦٠) + الكمية (٢٥٠/٥٠٠/مخصّص) + «إيقاف التذكير» كليًّا — لا وصفة إجبارية.
3. **تسجيل سريع + تراجع**: `addTodayWaterMl` يكتب **نفس** `waterMl` اليومي الذي تقرأه شاشة التغذية (مصدر واحد، لا ازدواج)؛ التراجع يعكس آخر كمية بالضبط. offline-first (localStorage).
4. **الأساس ظاهر**: «كل ٢٠ دقيقة أثناء الجلسة» — مبنيّ على وقت الجلسة الفعلي فقط؛ لا حرارة/مدة مُختلقة.
5. **سلامة المسارات**: `finish-confirm` 11/0 (م1) · `substitution` 20/0 (27/31) · مؤقّت الراحة سليم — البانر منفصل عنه.
6. **التغطية**: `test:hydration` (مضاف للبوابة) — التكرار من الوقت الفعلي · مصدر واحد (+تراجع، الوجبات محفوظة) · تحكّم بالتكرار/الكمية · الإيقاف · القصّ للحدود.

## المصدر الوحيد
