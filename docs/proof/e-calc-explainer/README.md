# إثبات حارة E — شرح الحساب

## النطاق

- إعادة بناء صفحة «كيف يحسب قِمّة أرقامك؟» من وثيقة المحتوى المعتمدة.
- إبقاء المعادلات في `calculators.ts` مصدر الحقيقة الوحيد.
- فصل خط الأساس المحسوب عن أي هدف محفوظ عُدّل يدويًا.
- إضافة الماء، معدل التغيّر المتوقع، والمعدل الفعلي من سجل الوزن.
- حالات التحميل والخطأ والفراغ والامتلاء، بالعربية والإنجليزية.
- دخول من الإعداد والتقدّم مع رجوع إلى مصدر الدخول.

## التحقق

```sh
node scripts/run-e-calc-explainer-proof.mjs
npm run typecheck
npm run lint
npm run build
npm run test:gate
```

يجب على المنسّق إضافة `test:e-calc-explainer` إلى `test:gate` من دون أن تعدّل حارة E ملف `package.json`.

رُوجعت الصفحة على عرض 393 بكسل. الأقسام الحسابية مطوية افتراضيًا، والنتيجة تبقى مرئية
في رأس كل قسم؛ فُتح قسما الطاقة والسعرات يدويًا للتحقق من المعادلة، نص درجة اليقين،
والفصل البصري بين خط الأساس والهدف المعدّل.

## قرارات لم تُغيّرها هذه الموجة

- معامل النشاط، العجز/الفائض الثابتان، قاعدة الماء، وقاعدة 7700 بقيت كما هي في المحرك.
- الصفحة تفصح عن درجة اليقين وحدود كل تقدير؛ لا تغيّر الصيغ.
- التعديل الآلي للأهداف يظل اقتراحًا فقط ولا يُنفّذ من هذه الصفحة.
