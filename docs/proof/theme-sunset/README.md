## مطابقة معايير DONE
1. **خيار الجدولة (66)** في إعداد المظهر، **اختياري ومطفأ افتراضيًا** (لقطة ب: النظام نشط، المبدّل مطفأ). الافتراضي يبقى «يتبع النظام».
2. **عند التفعيل**: يُطلب الموقع **عند-الحاجة** (نداء نظام يُستدعى فقط عند نقر المبدّل، بعد شرح الفائدة)؛ عند الرفض/التعذّر → **بديل يدوي دائم** (اختيار مدينة من قائمة إحداثيات ثابتة، بلا شبكة).
3. **الحساب**: `sunTimes` (معادلة الشروق القياسية، نقيّة) → داكن بعد الغروب، فاتح بعد الشروق، من الموقع/المدينة — لا اختلاق وقت.
4. **لا تبديل أثناء مجموعة**: `applyEffectiveTheme` يعيد استخدام حارس `isWorkoutActive` (المرحلة 4) — مؤجَّل أثناء الجلسة. مُثبَت في `test:theme`.
5. **التجاوز اليدوي يفوز**: `setTheme` يُطفئ الجدولة عند اختيار سمة يدوية — مُثبَت في `test:theme`.
6. **التغطية**: `test:theme` (26/0) — الجدولة اختيارية/مطفأة · sun-based day/night · التجاوز اليدوي يُطفئ ويفوز · لا تبديل أثناء مجموعة (مؤجَّل ثم يُطبَّق بعد الإنهاء) · صحّة `sunTimes`.
