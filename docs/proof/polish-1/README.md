## مطابقة معايير DONE
- **P0 — مفتاح الموقع:** أُضيف `NSLocationWhenInUseUsageDescription` إلى `ios/App/App/Info.plist` بنص عربي مبرَّر. **NATIVE CONFIRM:** `test:polish1` يقرأ الملف ويؤكّد وجود المفتاح (بعد `cap sync ios` أيضًا). قاعدة جديدة: أي إذن = فحص plist إلزامي.
- **P1 — التعريب (بلا قاموس جديد):** `V2_TAB_LABELS` (القاموس المركزي الذي تفرضه بوابة السياسة) صار ثنائي اللغة؛ `MobileShell` يقرأه حسب اللغة. أسماء المعدّات تُعرَّب في **طبقة العرض** عبر `src/lib/exerciseLabels.ts` (يعيد استخدام قاموس `src/i18n/dict/library.ts`) + `muscleLabel` الموجود — **بلا لمس بيانات التمارين**. اسم تمرين الإنهاء يفضّل الاسم المترجَم (لا عربي في EN).
- **P1 — اتجاه الأرقام:** الكتل المختلطة (سعرات/ماء) مغلّفة بـ`dir="ltr"` فقط، بلا لمس محاذاة البطاقة RTL.
- **التغطية:** `test:polish1` (مضاف للبوابة) — تسميات المعدّات/العضلات/التبويبات تتبع اللغة + حارس «لا عربي في EN» + وجود مفتاح الموقع. وبوابة السياسة (`test:policy`) بقيت خضراء (التبويبات ما زالت من `V2_TAB_LABELS`).

## ملاحظة تنفيذية (شفافية)
