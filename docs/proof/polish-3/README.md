## مطابقة معايير DONE
- **P2-A الأداء:** Sentry/Replay **لا يُحمَّل عند الإقلاع** — `monitoring.ts` يعيد قبل استيراد الـSDK إن لم يوجد DSN، والاستيراد ديناميكي (`import('@sentry/react')`) في حزمة كسولة مستقلّة. الحزمة الأولية (entry) **78KB ≤ 80KB** والإقلاع **≤ 140KB** (قياس). **شفافية:** «أكبر حزمة كسولة» (162KB) ليست Sentry — هي حزمة عرض التطبيق مرتبطة ببيانات التمارين في مسار الإقلاع؛ خفضها تحت 130KB يتطلّب فصل مجموعة بيانات التمارين عن توليد الخطة (Core) — مؤجّل كمهمة مخصّصة، لا يمسّ زمن الإقلاع.
- **P2-B التغذية:** ماء بكمية مخصّصة + إضافة سريعة؛ حصص الوجبة قابلة للضبط مع إعادة حساب حيّة موسومة «تقدير». **مصدر واحد:** وحّدت ماء التمرين ليمرّ عبر `addWaterToDay` نفسه (nutritionV2Model) — أصلحت ازدواجًا أدخلته موجة الترطيب (كانت تكتب `waterMl` في سجل مختلف). الآن شاشة التغذية ترى ماء التمرين والعكس (مُثبَت في `test:hydration`).
- **P2-C التنظيف:** حُذف يتيم `AppIcon-512@2x.png` (سبب تحذير Xcode)؛ README محدَّث بحالة v1.1 (Supabase/مزامنة/local-first/Capacitor)؛ وثائق v3 (`docs/design/v3/`) حاضرة على الفرع.
