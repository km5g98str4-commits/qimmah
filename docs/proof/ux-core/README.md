# UX Core — تقرير التحسين (ux/core-product-polish)

الأساس: `origin/design/v21-promotion` @ `80e31f7`. النطاق الحصري: App shell + التنقّل السفلي + الأسطح الخمسة
+ Settings + حالات loading/empty/error. **لا تغييرات في منطق البيانات/المتاجر/المصادقة/المزامنة/المعادلات.**

## ما أُنجز هذه الجولة — App shell (العمود الفقري المشترك لكل الأسطح)

| السطح | المشكلة قبل | التحسين | الدليل |
|---|---|---|---|
| App shell — لوحة المفاتيح | **لا يوجد رابط تخطٍّ**؛ مستخدم لوحة المفاتيح يمرّ عبر الهيدر بالكامل قبل بلوغ المحتوى | أُضيف رابط «تخطَّ إلى المحتوى» كأول عنصر قابل للتركيز، مخفي حتى التركيز (`sr-only focus:not-sr-only`)، يستهدف `#main-content` | تحقّق برمجي: أول عنصر قابل للتركيز = الرابط، يظهر عند التركيز (top 8px، تباين 16.8:1)، وتفعيله ينقل التركيز إلى `<main>`؛ + لقطة الرابط ظاهرًا |
| App shell — `<main>` | `<main>` غير قابل للاستهداف بالتركيز (لا هدف لرابط التخطّي) | أُضيف `id="main-content"` + `tabIndex={-1}` + `focus:outline-none` | تحقّق DOM: `mainInDom=true`, `tabindex=-1`, انتقال التركيز يعمل |
| App shell — منطقة الأمان | حشوة سفلية ثابتة `pb-24` غير واعية بـ safe-area → قد يُحجب المحتوى خلف الشريط السفلي على أجهزة النوتش | `paddingBottom: calc(var(--safe-bottom,0px) + 5.75rem)` على `<main>` | before/after لثلاثة profiles × 320/768/1280؛ خلوّ المحتوى من الحجب |
| التنقّل السفلي | (تُحقّق) نصّ + أيقونة + `aria-current` + `aria-label` للشريط موجودة سلفًا | لا تغيير — سليمة | مُراجَعة الكود |

> **الحركة:** انتقال الصفحات (`v2-screen-enter`) موجود ومحميّ بـ `prefers-reduced-motion` في `tokens.css:394` — لم يُغيَّر.
> **الهوية:** لا تغيير في الشعار/الألوان/التدرّجات؛ لا مكتبات جديدة؛ SVG محلي فقط.

## الأدلة (docs/proof/ux-core/)
- `before/` و`after/` — لقطات dashboard (Today) لثلاثة profiles (**fresh · reviewer · veteran**) على **320 · 768 · 1280** بكسل.
- **صفر overflow أفقي** و**صفر console errors** في كل الحالات (before و after على حدّ سواء) — مسجّل في مخرجات الالتقاط.
- رابط التخطّي: تحقّق لوحة مفاتيح (أول تركيز، يظهر عند التركيز، ينقل التركيز إلى `<main>`).

## رحلات التحقق المنفّذة
- fresh / reviewer / veteran تُحمَّل داخل الغلاف بلا انهيار (بذرة `run-demo-seed.mjs` + جلسة وهمية محلية).
- 320 / 768 / 1280: صفر overflow أفقي.
- keyboard-only: رابط التخطّي يعمل.
- reduced-motion: الحركة محميّة سلفًا في الطبقة.
- zero console errors عبر كل اللقطات.
