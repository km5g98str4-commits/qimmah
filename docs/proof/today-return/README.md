# إثبات — سياق «العودة بعد انقطاع» (شاشة 20)

`20-return-after-break.png` (iPhone 15 · 393×852pt @2x) — يُلتقط عبر `scripts/today-return-shot.mjs`
من الواجهة الحقيقية (Playwright، بلا خادم)، بزرع جلسة تمرين منتهية قبل ٥ أيام (لا جلسة اليوم).

## مطابقة معايير DONE
1. **سياق `returnAfterBreak`** في `TodayState`، يُشتق من فجوة نشاط فعلية (≥٣ أيام منذ آخر جلسة منتهية) من `getWorkoutSessions()` — لا تخمين. (`todayV2Model.ts`)
2. **نبرة لطيفة**: تحية «سعيدون بعودتك»، عنوان «تمرين عودة خفيف»، «ابدأ بـ ١٥ دقيقة اليوم» + خيار «أفضّل خطة اليوم كاملة» (بطاقة). صفر لوم، لا ذكر لعدد أيام الغياب، الستريك غير مُوبَّخ.
3. **«تقدّمك السابق محفوظ»** ظاهر في الهيرو + بطاقة «راجع تقدّمك — محفوظ بالكامل».
4. **القاعدة D**: النموذج نقي/قراءة فقط؛ تمرين العودة اقتراح يبدأ بنقر صريح (destination=workout) — لا تغيير خطة صامت.
5. **السياقات القائمة سليمة**: الأعمدة غير مقفلة بالكامل (ليست newUser)؛ مسار الإنهاء المؤكَّد (م1) لم يُمسّ — البوابة الكاملة خضراء بعد التعديل.
6. **التغطية**: `test:today-v2` أُضيفت له حالتان — ⑥ فجوة ≥٣ أيام → returnAfterBreak (نبرة بلا لوم، اقتراح لا تغيير، خيار الخطة الكاملة، السياقات الأخرى سليمة)، ⑦ فجوة يوم واحد → يبقى normal. 44 فحصًا، صفر فشل.

## ملاحظة صدق (شفافية)
الهيرو (عودة خفيفة · ١٥ دقيقة) وبطاقة «خطة كاملة» كلاهما يفتح **خطة اليوم الحقيقية نفسها** — «١٥ دقيقة» توجيه للتخفيف لا تمرين مولّد منفصل. لا يوجد مولّد «تمرين خفيف» مستقل بعد؛ ذلك تغيير في تدفّق التمرين خارج نطاق موجة «سياق اليوم». يُقترح كمتابعة صغيرة إن رغبت بفرق فعلي بين الخيارين.
