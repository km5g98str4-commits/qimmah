# إثبات حارة E — الإعدادات v3

## ما تغيّر

- خمس مجموعات عليا فقط: الحساب، التفضيلات، التذكيرات، الخصوصية والبيانات، وعن قِمّة.
- كل مجموعة تحمل وصفًا مختصرًا، وتُفتح كقسم مستقل بدل قائمة بطاقات متفرقة.
- جُمعت الخطة واللغة وربط الصحة تحت التفضيلات.
- جُمعت الخصوصية والتحليلات والنقل وإعادة الضبط تحت الخصوصية والبيانات.
- جُمعت نسخة البناء وشرح الحساب والتثبيت تحت عن قِمّة.

## ما لم يتغيّر

- منطق الحساب، الحذف، الخطة، التنبيهات، الصحة، النقل، التحليلات، أو التثبيت.
- شاشة الإعدادات الثانية داخل `ProfileV2.tsx` خارج نطاق الحارة ولم تُلمس.
- `package.json` لم يُمس؛ على المنسّق إضافة `test:e-settings` وربطه بـ`test:gate`.

## التحقق

```sh
node scripts/run-e-settings-proof.mjs
npm run typecheck
npm run lint
npm run build
npm run test:gate
```
