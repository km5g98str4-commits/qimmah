## مطابقة معايير DONE
1. **شاشة 68**: لكل مقياس (خطوات/وزن/قلب) مصدر + آخر تحديث + إجراء دقيق + فصل/حذف المستورد.
2. **الإذن عند-الحاجة (F6)**: `requestAuthorization` يُستدعى فقط عند نقر زر الربط لكل مقياس؛ إقلاع التطبيق (`refreshHealthKitStepsIfEnabled`) لا يطلب إذنًا أبدًا — مُثبَت في `scripts/native-bridge-proof.ts` (`requested === 0`).
3. **الرفض/عدم التوفّر**: بديل يدوي دائم (إدخال الخطوات، إدخال الوزن من التقدّم) + رسالة «لم يُمنح الإذن» بلا حجب.
4. **معدّل القلب**: «غير متوفّر — لم يُقترن جهاز» بلا رقم مُختلق (قاعدة الصدق، شاشة 35/78).
5. **الوزن**: استيراد `bodyMass` اختياري وموسوم `source: 'health'`؛ الافتراضي يدوي يبقى.
6. **التغطية**: `test:native-bridge` يغطّي الإذن عند-الحاجة · البديل اليدوي · HR بلا اختلاق · الوزن المستورد الموسوم.

## Native
- `ios/App/App/HealthKitStepsPlugin.swift`: أذونات مُوجَّهة بالمقياس + `getLatestBodyMass` + `getLatestHeartRate` (يعيد `null` عند غياب البيانات).
- `Info.plist › NSHealthShareUsageDescription`: مبرَّر لكل مقياس، والإذن يُطلب عند نقطة الاستخدام.
- `npx cap sync ios`: أخضر.
