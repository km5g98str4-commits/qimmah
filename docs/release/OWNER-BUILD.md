# بناء قِمّة صباحًا على iPhone زياد

## خطوات البناء

```bash
cd /Users/ziyad/qimmah-promotion
git switch design/v21-promotion
git pull --ff-only origin design/v21-promotion
npm ci
npm run build
npx cap sync ios
open ios/App/App.xcodeproj
```

**احذف تطبيق قِمّة من الهاتف قبل كل تثبيت يغيّر غلاف iOS أو الأيقونات أو التخزين.**

في Xcode: اختر مشروع **App** ثم Signing & Capabilities، حدّد فريق Apple Developer الصحيح، اختر جهاز **Ziyad iPhone** من شريط الوجهة، وافتح قفل الهاتف ووثّق الثقة إن طلب iOS ذلك، ثم اضغط **Run ▶︎**. معرّف الحزمة هو `com.qimmah.mobile`.

## قائمة اختبار يدوية — 15 بندًا

- [ ] افتح التطبيق وتأكد من ظهور شاشة الترحيب الداكنة بلا شريط «ثبّت التطبيق» داخل iOS.
- [ ] افتح إنشاء الحساب وتأكد أن زر الإنشاء يبقى معطّلًا حتى تحديد بوابة «عمري 12 سنة أو أكثر».
- [ ] افتح رابطَي الشروط وسياسة الخصوصية من بوابة 12+ وتأكد من ظهور الصفحتين الحقيقيتين.
- [ ] أكمل الإعداد وتأكد أن موافقة معالجة البيانات الصحية تمنع المتابعة قبل تحديدها.
- [ ] افرض فشل إعداد الخطة في نسخة التطوير، ثم تأكد من ظهور الخطأ وإتمام «أعد المحاولة».
- [ ] ابدأ تمرينًا، سجّل مجموعة، أغلق التطبيق في منتصف التمرين، ثم افتحه وتأكد من استعادة الجلسة.
