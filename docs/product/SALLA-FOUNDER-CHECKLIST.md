# سلة — قائمة المؤسس (بلا قرارات تقنية)

> كل ما يلي واجهة سلة أو لوحة `#/admin` بحساب المؤسس. لا شيء منه يستطيع الوكيل فعله
> نيابةً عنك (إصدار الأكواد يشترط JWT المؤسس، والمنتج والشراء في سلة). التفاصيل التقنية
> في [`SALLA-V1-EXECUTION.md`](./SALLA-V1-EXECUTION.md) — لا تحتاج قراءتها لتنفيذ هذه القائمة.

**ثابت لا يتغيّر:** `FOUNDER-RESERVE-001` لا يُلمس ولا يُرفع لسلة.

## أ · مرّة واحدة — المنتج (٥ دقائق)
- [ ] لوحة سلة → المنتجات → **منتج جديد** → النوع **بطاقة رقمية** (أكواد).
- [ ] الاسم: **قِمّة Premium** · السعر **١٩٫٩٩** · الوصف من `SALLA-MERCHANT-COPY-CHANGES.md` §5 (نصّ جاهز).
- [ ] اتركه **غير منشور**.
- [ ] افتح **إدارة الأكواد → رفع دفعة**، خذ لقطة شاشة لصفحة الرفع (أو نزّل قالبها إن وُجد) **وأرسلها لي**.
  هذا هو الشيء الوحيد الذي لا أستطيع معرفته بلا الشاشة. أضبط المحوّل عليه، ولا تحتاج تغييره بيدك.

## ب · الاختبار — `SALLA-TEST-001` (١٠ دقائق)
- [ ] قِمّة `#/admin` → **دفعات الشراء** → إصدار: الاسم `SALLA-TEST-001` · العدد **٥** · السبب `salla launch test`.
- [ ] نزّل الملف فور ظهوره (لن يظهر ثانيةً).
- [ ] حوّله (أرسله لي أو شغّل السطر الذي أعطيك إيّاه بعد الخطوة أ الأخيرة) ثم ارفعه في سلة داخل المنتج.
- [ ] بحساب عميل عادي: **اشترِ وحدة واحدة** (١٩٫٩٩) → يجب أن يظهر كود في صفحة الطلب والبريد.
- [ ] افتح قِمّة بحساب موثَّق → «عندك كود تفعيل؟» → الصق → **فعّل** ⇒ يفتح كل شيء (Premium).
- [ ] بحساب **ثانٍ** الصق نفس الكود ⇒ «هذا الكود مستخدم من قبل».
- [ ] بالحساب الأول: خروج ثم دخول ⇒ ما زال Premium.
- [ ] `#/admin` → دفعات الشراء → `SALLA-TEST-001`: المستردّ = ١.
- [ ] عطّل الدفعة: زرّ **تعطيل الدفعة** (`SALLA-TEST-001`) — يعطّل الأكواد الأربعة الباقية فقط.
- [ ] احذف الأكواد الباقية من منتج سلة.

## ج · الإطلاق — `SALLA-LAUNCH-001`
- [ ] `#/admin` → إصدار `SALLA-LAUNCH-001` · العدد **٢٠٠** · السبب `salla launch inventory` → نزّل الملف.
- [ ] حوّل وارفع (نفس طريقة ب).
- [ ] `#/admin` → الدفعة تعرض **المُصدَر ٢٠٠** = أسطر الملف = مخزون سلة.
- [ ] احذف الملف الخام من جهازك.
- [ ] **انشر المنتج.**

## إن تعطّل شيء
- الكود «ما ضبط»: `#/admin` → الأكواد → ابحث به → السبب يظهر (معطَّل/مستنفَد/غير موجود).
- ملف تسرّب قبل البيع: **تعطيل الدفعة** ثم إصدار `SALLA-LAUNCH-002` ورفعه بدل القديم. Premium الممنوح لا يُمسّ.
- استرجاع مالي: سلة تردّ المبلغ، وفي `#/admin` **سحب الوصول** للمستخدم بسبب مكتوب.
