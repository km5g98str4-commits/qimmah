# P6 Agent 2 — توسيع قاعدة بيانات الأطباق السعودية/الخليجية

## الهدف
مستخدم حقيقي أشار إلى قلة الأطباق السعودية المحلية في قاعدة الطعام. أضفنا مجموعة كبيرة
وأصلية (من معرفة عامة بالتغذية، وليست منسوخة من أي تطبيق آخر) من الأطباق السعودية/الخليجية
التقليدية بقيم غذائية **تقديرية**.

## ما تم
- ملف الملكية الوحيد الذي تم لمسه: [src/data/foodItems.ts](../../src/data/foodItems.ts)
- تصنيف جديد مضاف لنوع `FoodCategory`: **"أطباق سعودية / شعبية"**
- **63 طبقًا/عنصرًا جديدًا** أُضيفوا في هذا التصنيف (بالإضافة إلى الـ 28 عنصرًا
  الموجودة مسبقًا تحت تصنيف "أكلات سعودية/خليجية" — لم يُحذف أو يُعدَّل أي عنصر قديم).
- **إجمالي عناصر الطعام في قاعدة البيانات بعد الإضافة: 382 عنصرًا** (كان أقل قبل الدمج).
- كل عنصر يحتوي: اسم عربي + إنجليزي، تصنيف، حجم تقديم واقعي بالغرام، سعرات/بروتين/كارب/دهون
  تقديرية، وبعضها بألياف. أُضيفت `keywords` بالعربي (تهجئات بديلة) واللاتيني (نقحرة) لتسهيل البحث.
- تم الإبقاء على تنويه القيم التقديرية `FOOD_ESTIMATE_NOTE` كما هو دون تعديل، والقيم الجديدة
  متوافقة معه (لا ادعاءات دقة مطلقة).
- لا لمسة على العبارات (phrases)، الباركود، التمارين، أو خريطة العضلات — الالتزام بحدود الملكية.
- لا تراجع لأي من: 25 سلسلة مطاعم، تصنيف البقالة، أو المشروبات — الإضافة كانت مجاورة فقط.

## فحص عدم التكرار
تم فحص كل الملف بحثًا عن `id` أو `nameAr` مكرر بعد الإضافة (`grep -o "id: '...'" | sort | uniq -d`
و`nameAr` بنفس الطريقة) — **صفر تكرار**. تم اكتشاف تعارضين أثناء المراجعة (معصوب / كباب لحم
كانا موجودين مسبقًا بأسماء أخرى) واستُبدلا بعنصرين مختلفين (مكبوس دجاج، مقلوبة روبيان) قبل
الإغلاق النهائي.

## إثبات قابلية البحث + صحة الماكروز
تم تشغيل دالة `searchFood` الفعلية من الملف مباشرة (عبر `tsx`) للتأكد من أن العناصر الجديدة
تظهر بالعربي واللاتيني:

```
total items: 382
saudi-new count: 63
برياني => [ 'برياني دجاج', 'برياني لحم' ]
biryani => [ 'برياني دجاج', 'برياني لحم' ]
دبيازة => [ 'دبيازة لحم' ]
خمير => [ 'خمير' ]
هريس حلو => [ 'هريس حلو' ]
مشويات => [ 'مشويات لحم مشكلة', 'مشويات دجاج مشكلة' ]
```

كل عنصر يحمل `servingGrams` وماكروز مطابقة للحصة المذكورة في `servingLabelAr` (مثال:
برياني دجاج — صحن 350غ → 640 سعرة / 32غ بروتين / 68غ كارب / 26غ دهون)، بحيث يسجّل المستخدم
القيم الصحيحة فور اختيار الصنف من `QuickMealLogger`.

## المخاطر
- القيم غذائية **تقديرية عامة** وليست مأخوذة من أي مصدر ملكية أو تطبيق منافس — قد تختلف
  عن الواقع حسب طريقة الطبخ والكمية الفعلية (نفس تحذير بقية قاعدة البيانات).
- بعض الأطباق (حاشي، مغلقة، مراصيع، مصابيب) أقل شيوعًا وقد تحتاج مراجعة تسمية لاحقًا مع
  مستخدمين من مناطق مختلفة (نجدي/حجازي/جنوبي) لضبط التسميات المحلية البديلة.
- لم يتم النشر (Deploy) بحسب التعليمات — الدمج يقتصر على `integration/phase6` محليًا والدفع
  للـ remote فقط.
