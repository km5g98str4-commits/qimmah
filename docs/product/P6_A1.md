# P6 A1 — عبارات تحفيزية نجدية (Najdi Motivational Phrases)

## الملخص
إضافة مكتبة عبارات تحفيزية بلهجة نجدية (عربي + إنجليزي) تظهر عشوائيًا في بطاقة الترحيب بالرئيسية،
وتتغيّر مع كل فتح/دخول للتطبيق بدل العبارة الثابتة يوميًا السابقة.

## أين تم الربط
- ملف بيانات جديد: `src/data/motivationalPhrases.ts` — 50 عبارة `{ ar, en }` + `getRandomPhrase()`.
- سطح العرض: `GreetingCard` داخل `src/views/DashboardView.tsx` (بطاقة الترحيب أعلى الرئيسية).
  - استُبدل `phraseForDay()` من `src/data/dailyPhrases.ts` بـ `getRandomPhrase()` من الملف الجديد.
  - `src/data/dailyPhrases.ts` لم يُحذف (خارج نطاق ملكية هذه المهمة) لكنه أصبح غير مُستخدم من الرئيسية.

## منطق الدوران (Rotation)
- `getRandomPhrase()` يختار عبارة عشوائية عبر `Math.random()`.
- تُحسب مرة واحدة عبر `useMemo(() => getRandomPhrase(), [])` عند تركيب `GreetingCard` —
  أي تدور مع كل فتح جديد للتطبيق أو إعادة تحميل الصفحة (mount جديد)، وتبقى ثابتة أثناء نفس الجلسة/الشاشة.

## عربي/إنجليزي (ar/en)
- كل عبارة تحمل نسختين `ar` و`en`.
- العرض يتبع حالة اللغة الحالية في التطبيق (`lang` من `appPreferences`):
  `{lang === 'en' ? phrase.en : phrase.ar}`.

## البوابات (Gates)
- `npm run typecheck` ✅
- `npm run build` ✅ (تم التحقق من وجود نص العبارات الجديدة داخل حزمة `DashboardView` المبنية)
- `npm run lint` ✅ (بلا تحذيرات/أخطاء)

## المخاطر
- لم يتم تشغيل معاينة متصفح فعلية لهذا الفرع لأن أداة المعاينة في هذه الجلسة مرتبطة بمجلد مشروع آخر
  (`qimmah-deploy`) وليس بنسخة العمل المستنسخة لهذه المهمة (`~/qimmah-p6-a1`)؛ تم الاكتفاء بالتحقق عبر
  typecheck/build/lint وفحص محتوى الحزمة المبنية.
- ملف `src/data/dailyPhrases.ts` القديم بقي في المستودع بدون استخدام حاليًا (لم يُحذف لأنه خارج نطاق ملكية الملفات
  المحدّد لهذه المهمة).
