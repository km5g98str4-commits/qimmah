# قِمّة — Phase 3 · Agent 1: الإعداد والمنطق (Onboarding & Logic)

الهدف: إكمال منطق الإعداد وجعله «مضادّ للرصاص» — اسم المستخدم، تغطية إصابات كاملة،
أهداف نظيفة، وزن هدف يقود المدة، بوّابات التقسيمة، ومدخلات تغذية تؤثّر فعليًا.

كل مهمة مثبتة بالتشغيل الحقيقي على Node (تجميع `src` عبر esbuild ثم تشغيل سيناريوهات).
- الهارنس: `scripts/p3proof.mjs` (+ `scripts/build-proof.mjs`).
- التشغيل: `node scripts/build-proof.mjs && node scripts/.p3proof.bundle.mjs`.
- النتيجة: **45/45 اختبار ناجح**.
- التحقق القياسي: `npm run build` + `npm run lint` + `npm run typecheck` كلها تمرّ بلا أخطاء.

---

## 1) التقاط الاسم (مبكّر، اختياري، قابل للتخطّي)
- أُضيفت خطوة **«وش نناديك؟»** كأول خطوة في `PlanBuilder` (`optional` + زر «تخطّي»).
- حقل نصّي بسيط (`TextField`) بحدّ 24 حرفًا، بلا اسم وهمي افتراضي.
- التدفّق: `Answers.name` → `buildOnboardingProfile` (يُشذّب، ويبقى `undefined` عند التخطّي)
  → `profile.name` → `toLegacyProfile` → `identity.userName`.
- الرئيسية تعرض أصلًا `أهلًا يا {name}` (وإلا `أهلًا بك`) — `DashboardView.tsx:102`.
- **الإثبات:** الاسم يُشذّب ويُخزَّن؛ التخطّي/الفراغ/المسافات = لا اسم وهمي.

## 2) الإصابات — تغطية كاملة
- كانت مُوصّلة: الركبة/الكتف/الظهر فقط. أُضيفت: **الرسغ، المرفق، الكاحل**
  (كانت موجودة في واجهة الاختيار لكن المولّد يتجاهلها).
- `detectInjuries` توسّعت (عربي + معرّفات): `wrist|رسغ|معصم`, `elbow|مرفق|كوع`, `ankle|كاحل|كعب`.
- خرائط الاستبعاد (`INJURY_RISKY_IDS`) — محافظة (عند الشك نستبعد):
  - **الرسغ:** القبضة الثقيلة (رفعات/عقلة/تجديف بار)، حمل الوزن على الكفّ (ضغط/غطس)،
    تمرير البار المستقيم، الضغط الضيّق، سكل كرشر. نُبقي أجهزة/كيبل/دمبل بقبضة محايدة.
  - **المرفق:** كل التمريرات (bicep curls)، مدّ الترايسبس الثقيل والغطس والضغط الضيّق.
    نُبقي دفع الترايسبس بالكيبل (pushdown) والضغط بالجهاز/الدمبل.
  - **الكاحل:** القفز/الارتطام، رفع السمانة واقفًا، الاندفاع (lunges).
    نُبقي سمانة جالس/ليج برس والقرفصاء المدعوم والكارديو منخفض الارتطام.
- الكارديو (لهدف التنشيف) صار **يحترم فلتر الإصابات** (`addCutCardio` تأخذ `injuryOk`)
  — فمصاب الكاحل لا يحصل على حبل نطّ/برpees/high-knees.
- النسخة كما هي (بلا ادعاء طبي): «نستبعد بعض التمارين حسب اختيارك — راجع مختص لو عندك إصابة».
- **الإثبات:** لكل إصابة (٦ مناطق) خطة ٦ أيام متقدّمة + تنشيف: **صفر** من التمارين الخطرة،
  والخطة تبقى صالحة (كل يوم غير فارغ). تركيبة ٤ إصابات معًا: الخطة تبقى صالحة.

## 3) الأهداف = تنشيف/تضخيم فقط + هجرة القوة→تضخيم سليمة
- `goalChoices` = عنصران فقط (`cut`, `bulk`).
- الهجرة عند التحميل: `strength` → `bulk`، و`recomp` → `cut` (`migrateLegacyOnbGoal`).
- **الإثبات:** `cut→cutting`, `bulk→bulking`؛ ملف قديم بـ `strength` يُحمَّل `bulk`،
  و`recomp` يُحمَّل `cut` (تشغيل حقيقي عبر localStorage shim).

## 4) وزن الهدف يقود المدة (ETA) والتغيّر الأسبوعي
- يظهر فقط لـ cut/bulk (`showsTargetWeight`)؛ للحالة المتساوية = محايد (0 تغيّر / 0 أسبوع).
- الحساب في `computeTargets`: `diff = target − current` → تنشيف −0.5كجم/أسبوع، تضخيم +0.25كجم/أسبوع.
- **الإثبات:** تنشيف (90→80): Δ=−0.5، أسابيع=20. تضخيم (70→78): Δ=+0.25، أسابيع=32.
  هدف أبعد ⇒ مدة أطول (رتيبة). وزن مساوٍ ⇒ Δ=0 وأسابيع=0.

## 5) التقسيمة — بوّابات المستوى
- **المبتدئ:** لا يرى خطوة اختيار التقسيمة؛ و`buildOnboardingProfile` **يفرض** `splitMode='auto'`
  ويمسح `advancedSplit` (تثبيت على مستوى البيانات لا الواجهة فقط).
- **المتوسط/المتقدّم:** يختار من ٣ خيارات متمايزة: جسم كامل / علوي-سفلي / دفع-سحب-أرجل.
- المولّد يحترم الاختيار (`ADVANCED_SPLIT_ID` → `templateId`).
- **الإثبات:** مبتدئ (حتى لو أجاب advanced) → `auto` بلا `advancedSplit`. متقدّم لكل خيار
  → `templateId` المطابق والخطة صالحة. متوسط يحتفظ باختياره.

## 6) مدخلات التغذية في الإعداد تغيّر الخطة فعليًا
- `mealsPerDay` يغيّر عدد الوجبات في خطة التغذية.
- `dietPattern` / `mealDistribution` / `appetiteTiming` / `nutritionStyle` تُمرَّر عبر
  `toLegacyProfile` وتقود واجهة/توليد التغذية (بلا تكرار لعمل Agent 2 على الأطعمة).
- **الإثبات:** 3 مقابل 6 وجبات ⇒ عدد وجبات مختلف؛ نمط الأكل/التوزيع/التوقيت/الأسلوب كلها تمرّ.

## 7) تلميع الإعداد
- **شريط التقدّم والعدّاد دقيقان:** شاشة «البناء» لم تعد تُحتسب في المقام
  (`formTotal = total − 1`) — آخر خطوة نموذج = 100%.
- **زر الرجوع** يعمل (وعلى أول خطوة يخرج للبداية).
- الخطوات شرطية بالكامل (لا خطوات ميتة): وزن الهدف/الانتظام/التقسيمة/الوجبات تظهر حسب السياق.
- كل النسخ الجديدة **خليجية** (وش نناديك؟ / اختياري — نستخدمه نرحّب فيك …).

## المخاطر والملاحظات
- الاستبعاد **محافظ عمدًا**: قد يُقصي بدائل آمنة نسبيًا (مثلًا كل التمريرات لمصاب المرفق).
  مقبول للسلامة؛ الخطة تبقى صالحة لأن المولّد يتخطّى الفتحات غير القابلة للملء ويكمّل من عضلات اليوم.
- كشف الإصابة نصّي (معرّفات + مرادفات عربية)؛ الإدخال من واجهة قوائم ثابتة فلا لبس.
- لا ادعاءات طبية في أي نسخة.
- ملف `scripts/.p3proof.bundle.mjs` ناتج بناء مؤقّت (مُستبعَد في `.gitignore`).
