## جدول البدائل (للمراجعة — التفصيل الكامل ثنائي اللغة في تقرير A1 وبنية `machineAlternatives.ts`)
لكل جهاز في الكتالوج بديل **دمبل** وبديل **كيبل** (مشاركة عدوانية للبدائل لتوفير ميزانية GIF). أبرز القرارات:
- face-pull هو بديل الكيبل الإلزامي لـ reverse-pec-deck ✔ (منفّذ)
- الكوادز الأربعة تتشارك goblet-squat (دمبل) و⚠ bodyweight-squat (بديل صادق — لا كيبل منطقي)
- البطات: ⚠ لا كيبل منطقي — بدائل وزن جسم/دمبل بتسمية صادقة (cableIsFallback)
- جديدان أُنشئا للبدائل: dumbbell-sumo-squat، cable-hip-adduction

## أصول GIF (زياد — على الماك)
- المطلوب 73 (38 جهازًا + 35 بديلًا) / متوفر 29 / **ناقص 44**
- **الطلبات المخططة: 88 ≤ 150 ✅** (بحث+تنزيل لكل GIF؛ المفتاح لديه ~367)
- الأوامر الدقيقة والقائمة الكاملة في `docs/product/P12_ASSETS.md`:
```bash
cd gym-os-template

git add public/exercise-gifs src/data/exerciseGifs.ts && git commit
```

## ملاحظات وقرارات مسجّلة
- **home/bodyweight**: «أجهزة فقط» تستحيل فيزيائيًا بلا أجهزة — تبقى الخطط المنزلية على معدّاتها (قرار مُعلَّم لمراجعة زياد).
- قالب fat-loss يُبقي خواتم الكارديو (أجهزة كارديو، ليست مقاومة حرة).
- انحرافان مقصودان في الاستبدال لتفادي التكرار داخل اليوم: deadlift→glute-drive-machine (full-body)، romanian-deadlift→glute-drive-machine (UL Lower A) — مُعلَّمان.
- اكتشاف: `lat-pulldown.gif` لم يكن موجودًا أصلًا (خلافًا لنص الـ brief) — ضمن قائمة الناقص.
- الأيقونة: إثباتات قبل/بعد بالحجم الحقيقي في `docs/product/p12-icons/`.
