# P5 — وسائط التمارين المتحرّكة (WorkoutX GIFs، vendored)

الهدف: جلب GIF متحرّك لتمارين قِمّة **مرّة واحدة وقت البناء** من WorkoutX، تخزينه محليًا
(`public/exercise-gifs/<id>.gif`) بحيث لا يحتاج العرض وقت التشغيل أيّ مفتاح أو شبكة، ثم تفضيله
على الصورة الثابتة لتوحيد شكل الوسائط (معالجة شكوى «اختلاف الأنماط»).

## الحالة: ⛔ مُوقَف عند طلب الاختبار — مضيف WorkoutX خارج قائمة السماح للشبكة

| البند | القيمة |
|---|---|
| المسار المؤكّد | ❌ لم يُؤكَّد — الطلب لم يصل إلى WorkoutX |
| التمارين المطابَقة | 0 / 174 |
| طلبات WorkoutX المستهلكة | **0** (الطلب حُجب في بوّابة الشبكة قبل الوصول للـ API) |
| الحصّة المتبقية | **500 / 500** (سقف مدى الحياة — لم يُمَسّ) |
| ملفّات GIF مُلتزَمة | 0 |
| البوّابات (build / lint / typecheck) | ✅ خضراء |

## ماذا حدث بالضبط

طلب الاختبار الوحيد (`node scripts/fetch-workoutx-media.mjs --probe`) رجع:

```
→ [req 1/300] GET https://api.workoutxapp.com/exercises
← 403 Forbidden • content-type: text/plain
  Host not in allowlist: api.workoutxapp.com.
  Add this host to your network egress settings to allow access.
```

هذا الرفض من **بوّابة الشبكة (egress proxy)** لهذه البيئة، لا من WorkoutX. المضيف
`api.workoutxapp.com` غير مُدرَج في سياسة السماح، فلم يصل الطلب إلى الـ API إطلاقًا،
ولم تُستهلك أيّ حصّة من المفتاح. سياسة البيئة تمنع الالتفاف حول هذا الحجب — لذا أُوقِف
التشغيل وسُجّل المضيف المحجوب (كما طلبت مواصفة المهمّة: توقّف بعد طلب الاختبار الواحد،
لا تحرق حصّة).

## ما الذي أُنجِز وسُلّم (جاهز، ينتظر فتح الوصول فقط)

1. **`scripts/fetch-workoutx-media.mjs`** — سكربت الجلب الكامل:
   - يقرأ المفتاح من `process.env.WORKOUTX_API_KEY` فقط (لا يُكتب في أيّ ملف مُلتزَم)،
     ترويسة `X-WorkoutX-Key`، القاعدة `https://api.workoutxapp.com`.
   - **طلب اختبار أوّلًا** لتأكيد المسار + شكل الاستجابة، ويطبع عيّنة (بلا المفتاح) + الحصّة المتبقية.
   - يتوقّف فورًا إن كان الشكل غير مؤكّد أو المصادقة مرفوضة (كما حدث الآن).
   - **حارس الميزانية:** سقف صارم 300 طلب، عدّاد جارٍ يُطبَع مع كل طلب، توقّف عند إشارة
     نفاد الحصّة (429 أو ترويسة remaining=0)، بلا حلقات غير محدودة.
   - عند نجاح الشكل: يطابق التمارين بالاسم/العضلة/الأداة، **يُنزّل كل gif** إلى
     `public/exercise-gifs/<id>.gif` (تنزيل من CDN بلا مفتاح — لا يُحتسب على الحصّة)،
     ويكتب `src/data/exerciseGifs.ts` (مُعرّف → مسار محلّي).

2. **`src/data/exerciseGifs.ts`** — خريطة `id → مسار gif محلّي` + `getExerciseGif()`
   (فارغة الآن، يملؤها السكربت آليًا عند التشغيل الفعلي).

3. **`src/components/ExerciseMedia.tsx`** — سلسلة الأفضلية موحّدة الآن:
   **GIF محلّي متحرّك → (GIF بعيد) → صورة ثابتة (free-exercise-db) → بديل أنيق.**
   الوسيط يُعرض بإطار موحّد (`object-cover` + ارتفاع ثابت + تدرّج داكن) لتناسق الشكل بين
   كل التمارين بصرف النظر عن مصدر الصورة.

## كيف يُكمَل العمل (خطوة واحدة بعد فتح الوصول)

أضِف `api.workoutxapp.com` إلى إعدادات egress الخاصّة بالبيئة، ثم:

```bash
export WORKOUTX_API_KEY="…"          # لا يُلتزَم أبدًا
npm run media:gifs:probe             # طلب اختبار واحد — راجع العيّنة + الحصّة
npm run media:gifs                   # تشغيل كامل مرّة واحدة: يجلب + يُنزّل + يكتب الخريطة
npm run typecheck && npm run build   # تأكيد البوّابات
git add public/exercise-gifs src/data/exerciseGifs.ts && git commit
```

المكوّن سيلتقط الـ GIFات تلقائيًا (بلا تعديل كود إضافي) لأن سلسلة الأفضلية مُوصّلة سلفًا.

## مخاطر / ملاحظات

- **الحصّة:** المفتاح له سقف 500 طلب مدى الحياة. السكربت يجلب القائمة الكاملة في طلب واحد
  (ثم ينزّل الملفّات من CDN بلا مفتاح)، فالاستهلاك المتوقّع ≈ 1–4 طلبات فقط. الحارس الصارم 300
  خطّ أمان لا هدف.
- **شكل الاستجابة غير مؤكّد:** لم نصل للـ API، فلم نتحقّق من أسماء الحقول الفعلية. السكربت
  يتعامل مع أشكال شائعة (`gifUrl`/`gif`/`animatedUrl`…) ويتوقّف ويطبع العيّنة إن اختلف الشكل
  قبل حرق أيّ حصّة.
- **الأمان:** المفتاح يُقرأ من البيئة فقط ولا يظهر في أيّ مخرجات (دالة `redact`) ولا يُلتزَم.
