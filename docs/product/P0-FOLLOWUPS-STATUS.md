# حالة بنود P0 اللاحقة

هذه الجولة راجعت البنود اللاحقة بعد الإصلاحات السبعة، وربطت كل بند بمسار حقيقي أو فجوة معلنة:

| البند | الحالة | الدليل |
|---|---|---|
| بطاقات لوحة اليوم | مكتمل وموجود | `TodayV2` يعرض أربع بطاقات تنفيذية (تمرين، وجبة، ماء، تقدّم) بوجهات حقيقية؛ `npm run test:today-v2` يثبت حالات المستخدم والبطاقات بلا إحصاء ميت. |
| RPE | مكتمل | منتقي RPE اختياري يظهر للمستوى المتوسط والمتقدم فقط، ويحفظ القيمة مع سجل المجموعة؛ `npm run test:rpe-level` و`npm run test:fixforward`. |
| الوسائط | مكتمل بصدق | الصور المحلية لا تُعرض إلا من سجل provenance، والناقص يبقى placeholder معلنًا؛ `npm run proof:media` و`npm run test:media-pipeline`. |
| الوجبات المحفوظة ونسخ وجبة | مكتمل | شاشة التغذية تعرض الأيام ذات التفاصيل الفعلية وتتيح نسخ الوجبة إلى اليوم؛ النسخ يرفض الوجبة الفارغة برسالة ثنائية؛ `npm run test:saved-meals` و`npm run test:nutrition-history`. |
| جاهزية iOS | جاهز بنيويًا، تحقق الجهاز مؤجل | manifest والأيقونات و`Info.plist` وتعليمات Safari موجودة، واختبارات native/polish تتحقق من المفاتيح؛ التثبيت الفعلي على جهاز iPhone لا يمكن ادعاؤه من بيئة CI ويظل تحققًا يدويًا قبل الإصدار. |

لا تُنشئ هذه الصفحة أرقامًا أو بيانات تجريبية؛ هي جرد لما يقرأه التطبيق فعلًا وما بقي خارج قدرة بيئة الاختبار.
