## Task 3 — Diet filter (works with Agent 1's `dietPattern`)

New module **`src/lib/dietFilter.ts`** classifies every ingredient by source (`meat` / `fish` / `egg` / `dairy` / `honey` / `plant`) and applies the pattern rule:

| Pattern | Excludes | Keeps |
|---|---|---|
| `vegetarian` | meat, fish/seafood | egg, dairy, plant |
| `vegan` | meat, fish, egg, dairy, honey | plant only |
| `pescatarian` | meat (land animals) | fish/seafood, egg, dairy, plant |
| `none` / `low_carb` / `keto` | — (macro patterns, no source exclusion) | all |

Wiring:
- **Auto-meals:** `generateNutrition` runs each slot template through `pickTemplateForDiet` — a non-compliant template (e.g. chicken for a vegetarian) is swapped for the highest-protein compliant template of the same meal type, falling back to any compliant template if the type has none.
- **Suggestions/swap:** `mealAlternatives(meal, dietPattern)` filters candidates by `templateAllowedForDiet`; `NutritionPlanSection` passes `customization.profile.dietPattern`.
- **New plant-forward templates + `tofu` ingredient** were added so vegetarian/vegan users have compliant lunch/dinner/breakfast options (previously there were none): `lentil-rice-bowl`, `chickpea-quinoa-bowl`, `tofu-veggie-rice`, `lentil-soup-bread`, `veggie-omelet`, `tofu-scramble`.

**Proof:**
- `ingredientSource` maps chicken→meat, salmon→fish, eggs→egg, whey-protein→dairy, lentils→plant ✅
- auto-meals `[vegetarian]` sources = {egg, plant, dairy, honey} → **no meat/fish** ✅
- auto-meals `[vegan]` sources = {plant} only ✅ — including the **5-meals/day edge case** (post-workout `protein-shake` slot swapped away from dairy) ✅
- auto-meals `[pescatarian]` exclude meat but a fish template stays available ✅
- `[none]` keeps meat (no exclusion) ✅
- `mealAlternatives(…, 'vegetarian')` returns 4 alts, none containing meat/fish ✅

No health claims added anywhere — this is ingredient filtering only.

## Task 4 — Food search quality (fast, Arabic-first, misspellings/synonyms, per-portion + per-100g)

- **`normalizeSearch`** strips tashkeel/tatweel and unifies alef forms, `ة→ه`, `ى→ي`, hamza carriers — so `كبسه` (common misspelling) matches `كبسة`.
- **Ranked, Arabic-first:** exact AR (0) → AR prefix (1) → AR substring (2) → EN prefix/substring (3–4) → keyword (5–6), stable within score. O(n) over ~294 items — fast.
- **Synonyms** via latin + AR keywords (e.g. روبيان also matches `جمبري`/`قمبري`/`shrimp`/`prawn`).
- **Per-portion + per-100g** now shown together in the selected-food card of `QuickMealLogger`.

**Proof:** `normalize(كبسة)==normalize(كبسه)` ✅ · `search('كبسه')` → 6 results, top = كبسة دجاج ✅ · `search('albaik')` → 6 restaurant items ✅ · `search('جمبري')` → روبيان ✅ · `search('دجاج')` top is an Arabic-name match ✅
