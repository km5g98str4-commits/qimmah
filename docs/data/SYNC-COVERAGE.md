# تغطية المزامنة الفعلية — الحالة والتوصية (موجة سلامة البيانات v1)

**الحالة:** المزامنة **مطفأة افتراضيًا** (`VITE_SYNC_ENABLED === 'true'` حصريًا)، ومحروسة بـ: مستخدم موثَّق مطابق + ليست جلسة استعادة + **ليست حالة تبنٍّ معلّق** (جديد هذه الموجة). local-first: كل شيء يعمل دون إنترنت؛ المشغّلات: online / عودة الواجهة / appStateChange + بعد الترطيب من السحابة.

## ما تتم مزامنته (9 جداول)
`profiles` (onboarding) · `workout_sessions` · `exercise_history` · `measurement_logs` (الآن بـ`updated_at`) · `daily_logs` (حزمة: يوميات + تغذية + ماء + مكملات + أدوية — مجاميع) · `step_logs` · `achievements` · `custom_plans` · `todos`.

**الحسم:** LWW لكل سجل (هذه الموجة) — طوابع البيانات الداخلية أولًا (`finishedAt`/`lastCompletedAt`/`updatedAt`) ثم عمود `updated_at`؛ المعلّق بطابور الرفع محمي؛ التساوي/غياب الدليل = المحلي يبقى؛ لا حذف صامت. **الحذف المتزامن غير مبني** — لا يوجد مسار حذف يصل السحابة اليوم (`enqueueSyncDelete` موجود للبنية)؛ عند الحاجة: tombstones بطابع، موثَّق كترشيح.

## ما لا تتم مزامنته اليوم
| المخزن | التقييم |
|---|---|
| التخصيص/الأهداف (`customization`) | **يجب إضافته لاحقًا** (أعلى قيمة: الخطة والأهداف عبر الأجهزة) — بعد توسيم المفاتيح |
| سجل التعافي (`recovery-log`) | يُضاف لاحقًا (موسوم أصلًا) |
| تفضيلات التذكيرات/الإشعارات | يُضاف لاحقًا (تفضيل حساب) |
| هدف/مصدر الخطوات | يُضاف مع نقل مفاتيح الخطوات |
| أصناف تغذية اليوم (`nutrition:v2`) | قرار منتج: التاريخ التفصيلي أصلًا يُمسح يوميًا (فجوة موثقة في تدقيق البنية) — يُحسم مع إعادة تصميم تاريخ الطعام |
| إعدادات الأقراص/الإحماء/الترطيب/اليد | تفضيلات خفيفة — يُقيَّم لاحقًا |

## ما لا ينبغي مزامنته
رمز الجلسة (`supabase-auth`) · طوابير/نسخ المزامنة نفسها · كاش OFF والمنتجات (عام قابل لإعادة الجلب) · أعلام الواجهة/التثبيت · `lastUser`/`dataOwner`/سجل الهجرات (محاسبة جهاز) · **الحجر** (`quarantine:*` — بيانات غير منسوبة، يحظر رفعها بالتعريف).

## توصية الموجة التالية (بالترتيب)
1. نقل مفاتيح `owner-suffix` (خطة DATA-OWNERSHIP) — يفتح مزامنة `customization` بأمان.
2. `updated_at` لصفوف المخازن المساعدة (خطوات/إنجازات/خطة/todo) ⇒ LWW كامل بلا الاعتماد على الطابور.
3. tombstones للحذف المتزامن إن لزم (قياسات محذوفة مثلًا).
4. ضم `recovery-log` + تفضيلات التذكيرات للجداول.
