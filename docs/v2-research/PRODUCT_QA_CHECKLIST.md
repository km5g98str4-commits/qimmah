# Qimmah V2 — Product QA Checklist

قائمة فحص يدوي شاملة لمنتج **قِمّة V2** بعد دمج الـ master.
الهدف: التحقق أنّ كل التدفقات تعمل، وأنّ مصدر الحقيقة هو **إجابات الإعداد فقط** (لا بيانات وهمية).

- **التطبيق:** Frontend فقط (React 18 + TS + Vite)، تخزين عبر `localStorage`، RTL عربي.
- **التشغيل:** `npm run dev` ثم افتح الرابط (افتراضيًا `http://localhost:5173`).
- **الأجهزة المرجعية:** اختبر عند عرض **320px** و**768px** و**1280px** (DevTools → Toggle device toolbar).

## كيف تستخدم هذه القائمة
1. ابدأ كل قسم من حالة نظيفة عند الحاجة: DevTools → Application → Local Storage → **Clear**، أو نفّذ في الـ Console:
   ```js
   localStorage.clear(); location.hash = '#/start'; location.reload()
   ```
2. ضع علامة ✅ نجاح / ❌ فشل، وسجّل أي رسالة Console حمراء.
3. أي حالة تلمس بيانات حقيقية: تحقّق من المفتاح المناسب في Local Storage بعدها.

## 3) 9-step onboarding validation (تحقق الإعداد)
> ابدأ نظيفًا، ثم `#/setup`. تأكّد أنّ العدّاد يعرض **/9**.

**ترتيب الخطوات:** 1) الهدف 2) الجنس 3) العمر 4) الطول 5) الوزن (+ وزن الهدف الشرطي) 6) الخبرة (+ الانتظام الشرطي) 7) مكان التمرين 8) أيام التمرين 9) شاشة البناء.

| # | الحالة | الخطوات | المتوقع |
|---|---|---|---|
| 3.1 | أربعة أهداف فقط | الخطوة 1 | تظهر **4 فقط**: تضخيم / تنشيف / تركيب الجسم / زيادة القوة |
| 3.2 | لا أهداف مكررة | الخطوة 1 | **لا** «بناء عضل»، **لا** «نزول وزن»، **لا** «لياقة عامة» |
| 3.3 | منع التقدّم بلا اختيار | الخطوة 1 بدون اختيار | زر «التالي» معطّل |
| 3.4 | منزلق العمر | الخطوة 3 | منزلق 14–80 (لا حقل نص حر)، الافتراضي 25، قابل للتحريك بلوحة المفاتيح (أسهم) |
| 3.5 | منزلق الطول | الخطوة 4 | منزلق 120–220 سم |
| 3.6 | **وزن 5000 محظور** | الخطوة 5 | المنزلق لا يتجاوز **250 كجم** — يستحيل إدخال 5000 |
| 3.7 | BMI رقمي فقط | الخطوة 5 بعد ضبط الوزن | يظهر «BMI: «رقم»» فقط — **بلا** ممتاز/طبيعي/بدين ولا تشخيص |
| 3.8 | وزن الهدف يظهر للتنشيف/التضخيم فقط | الخطوة 5 | منزلق وزن الهدف يظهر فقط عند هدف **تنشيف** أو **تضخيم**؛ يختفي مع تركيب الجسم/القوة |
| 3.9 | **تنشيف: هدف أعلى من الحالي محظور** | هدف تنشيف، اجعل وزن الهدف > الحالي | رسالة «وزن الهدف للتنشيف لازم يكون أقل من وزنك الحالي» + زر «التالي» معطّل |
| 3.10 | **تضخيم: هدف أقل من الحالي محظور** | هدف تضخيم، اجعل وزن الهدف < الحالي | رسالة مماثلة + زر معطّل |
| 3.11 | **المبتدئ يتخطّى الانتظام** | الخطوة 6 اختر «مبتدئ» | سؤال الانتظام **يختفي** والزر يصبح فعّالًا؛ يُخزَّن `consistency: "never"` |
| 3.12 | **المتقدّم يُظهر الانتظام** | الخطوة 6 اختر «متقدّم» (أو متوسط/مستجد) | يظهر «كيف انتظامك حاليًا؟» والزر يبقى معطّلًا حتى الاختيار |
| 3.13 | لا تناقض السنوات | اختر «متقدّم» ثم انتظام | لا يوجد خيار «ما تمرنت أبدًا» مع «متقدّم» — التناقض القديم اختفى |
| 3.14 | أنواع الصالات | الخطوة 7 | 4 خيارات: صالة كاملة / صالة صغيرة / جيم منزلي / وزن الجسم |
| 3.15 | عدّاد الأيام 3–6 | الخطوة 8 | عدّاد +/-؛ الحد الأدنى 3 (زر − معطّل عند 3) والأقصى 6؛ نسخة محايدة |
| 3.16 | توصية الأيام | الخطوة 8 | الموصى به: مبتدئ/مستجد = 3، متوسط = 4، متقدّم = 5؛ زر «الموصى به» يضبط القيمة |
| 3.17 | لا اختيار تقسيمة | كامل التدفق | **لا** سؤال «أي تقسيمة؟» ولا «أي أيام تفضّل؟» |
| 3.18 | شاشة البناء | الخطوة 9 | تقدّم 0→100%، نص «نبني خطتك المثالية…»، ~2–4 ثوانٍ ثم اللوحة |
| 3.19 | حفظ المسودة | بعد كل خطوة، افحص `qimmah:onboarding:v1.draft` | المسودة تُحدَّث بعد كل خطوة، و`lastStep` يتقدّم |
| 3.20 | استئناف المسودة | في منتصف الإعداد حدّث الصفحة | يعود للإعداد (لا للوحة) مع استرجاع الإجابات من المسودة |
| 3.21 | الرجوع من الخطوة الأولى | على 1/9 اضغط رجوع | يعود لشاشة `start` |

| 4.9 | خطة حقيقية لا قالب وهمي | بعد الإكمال | `workoutPlan.days.length > 0` و`nutritionPlan.meals.length > 0` مولّدة من الإجابات |
| 4.10 | جدول أسبوعي متّسق | اللوحة/التقدّم | عدد أيام التمرين = الأيام المختارة، الباقي «راحة» |
