| | |
|---|---|
| **الخطورة** | حاجب — **للنشر لا للمنتج** |
| **المسار** | لا يوجد (طبقة بنية تحتية) |
| **المتوقَّع** | `wrangler pages deploy dist --project-name qimmah --branch founder-qa-preview` ينتج رابط معاينة |
| **الواقع** | بوّابة الخروج تردّ **403 على CONNECT** لكل مضيف Cloudflare |
| **صاحبه** | **المؤسس** — تنفيذ محلّي (§٦ في `PREVIEW-SAFETY.md`) |

**خمسة مسارات جُرّبت كلّها وسقطت — بالقياس لا بالافتراض:**

| المسار | النتيجة المقيسة |
|---|---|
| خوادم Cloudflare MCP الأربعة (`mcp` · `builds` · `docs` · `observability`) | تحتاج OAuth (الجلسة غير تفاعلية) **و**مضيفاتها الأربعة `403 connect_rejected` |
| `wrangler whoami` | `You are not authenticated` — لا اعتماد في البيئة |
| `wrangler pages project list` بتوكن تجريبي | `fetch failed` — وسجلّ الوكيل يسجّل `403 api.cloudflare.com:443` في **نفس الثانية** |
| `curl` إلى `api.cloudflare.com` · `dash.cloudflare.com` · `qimmah-8qp.pages.dev` | `CONNECT tunnel failed, response 403` للثلاثة |
| متصفّح Chromium حقيقي على `dash.cloudflare.com` | `net::ERR_TUNNEL_CONNECTION_FAILED` |

**الحاجزان مستقلّان:** لا اعتماد **ولا شبكة**. فحتى لو مُنح توكن، لا يصل الطلب.
و`README` الوكيل صريح: «403/407 = رفض سياسة المؤسسة — **لا تُعِد المحاولة ولا
تلتفّ حولها، بل أبلغ عن المضيف المحجوب**». فلم أحاول التفافًا.

**وأثر جانبي مهم:** `*.pages.dev` محجوب أيضًا ⇒ **التحقّق الحيّ من أي رابط منشور
مستحيل من هنا كذلك**، أيًّا كان من ينشر.

## F-4 · ℹ️ لا دليل WebKit على هذا الرأس

مقيس الآن لا منقول: `pw[webkit].launch()` ⇒ `Executable doesn't exist at
/opt/pw-browsers/webkit-2311/pw_run.sh`، و`npx playwright install webkit` ⇒
`Download failure`. المجلد يحمل Chromium وffmpeg فقط.

**الأثر:** iOS Safari — متصفّح الجمهور المستهدَف — بلا تغطية آلية.
**ما يرفعه:** جهاز iOS في يد المؤسس أثناء المراجعة.

## F-5 · ⚠️ **تحقّق قبل النشر: هل مشروع Pages موصول بـGit؟**

لم أستطع فحص لوحة Cloudflare (F-1)، وهذا سؤال **أمني** لا إجرائي:

> إن كان مشروع `qimmah` موصولًا بـGit، فدفع هذا الفرع **قد يكون أنشأ نشرة معاينة
> آليًّا مبنيّة بـ`npm run build`** — أي **وضع الإنتاج**، بالعنوان والمفتاح
> المخبوزين. وتلك بالضبط النسخة غير الآمنة التي تحرسها هذه الموجة.

**ما يرجّح أنه رفع مباشر (Direct Upload) لا Git:**
`docs/launch/DEPLOY-TRUTH-VERIFICATION.md` أثبت أن البناء المنشور كان متخلّفًا
**٣١٨ التزامًا** عن `main` — وهو ما لا يحدث في مشروع موصول بـGit ينشر كل دفعة.
و`docs/deploy/WEB-CUTOVER.md` §٤ يصف النشر بأمر `wrangler pages deploy` يدوي.

**لكنه ترجيح لا إثبات.** الفحص بأمر واحد:

```bash
npx wrangler pages deployment list --project-name qimmah
```

لأنها **ليست** بناء المعاينة الآمن. البناء الآمن يأتي من `build:founder-preview`
