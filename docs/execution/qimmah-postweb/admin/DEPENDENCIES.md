## ١. لماذا لم تُوصَل اللوحة بقشرة التطبيق

سباق **الويب السيادي** يعمل **الآن** على `App.tsx` وقشرة التطبيق ومسارات
`appRoutes.ts` نفسها. وحقن مسار `admin` فيها اليوم يعني تعارضًا مؤكّدًا في
ثلاثة ملفات مشتركة، ودفعه إلى الحارة الأخرى وهي في منتصف موجتها.

**فالقرار:** تُبنى اللوحة **وحدة مستقلّة بذاتها** تستقبل كل ما تحتاجه بالخصائص،
وتُوصَل **حين يهبط الرأس النهائي** — بخطوة موصوفة هنا بالملف والسطر.

> هذا تطبيق مباشر لـ§1.4/٤ من الميثاق: **«إن اضطرت حارتان لنفس الملف فالجواب:
> لا»** — يُعاد تحجيم الموجة أو تُسلسَل الموجتان. وهذا هو التسلسل.

**الحالة الآن — قابلة للتحقّق آليًا** (يفحصها `test:admin-dashboard`، البند ١٨):

- `src/App.tsx` — **لم يُمَسّ**، ولا يذكر اللوحة.
- `src/lib/appRoutes.ts` — **لم يُمَسّ**، ولا مسار `admin` فيه.
- `package.json` — **لم يُمَسّ** (§1.4/٢: بؤرة تصادم محجورة، المنسّق وحده يلمسها).
- `src/lib/icons.ts` — **لم يُمَسّ**: كل أيقونات اللوحة موجودة في الخريطة أصلًا،
  فلم تلزم إضافة واحدة. (وهذا مقصود: الملف بؤرة تصادم مع الحارة الأخرى.)
- `supabase/**` — **لم يُمَسّ**: قُرئ عقد المخطّط وسياسات RLS فقط.

## ٢. خطوة الوصل — ماذا يُفعل بالضبط حين يهبط الرأس

### ٢أ) قبل أي شيء: تصريح الدور

**لا تُوصَل اللوحة قبل وجود مصدر يُصدر `qimmah_role = 'founder'` في
`app_metadata`.** وصلها قبله يعطي شاشة منع دائمة لا شاشة عمل — وهو سلوك صحيح،
لكنه لا يفيد أحدًا.

الأثر المطلوب على الخادم (**خارج صلاحية هذه الحارة** — `supabase/**` لا يُعدَّل هنا):

1. مصدر يحقن الادّعاء في `app_metadata` لحسابات المؤسس.
2. سياسة قراءة إدارية أو دالة `security definer` تقرأ تجميعات `public.profiles`
   خلف فحص الدور نفسه.

> **لا يُقرأ الدور من `user_metadata` بأي حال** — المستخدم يكتب فيه بنفسه.
> يحرس هذا `test:admin-access-denial` باختبار طفرات يقتل هذه الحالة بالاسم.

### ٢ب) الوصل في القشرة — ثلاثة تعديلات لا أكثر

| # | الملف | الفعل |
|---|---|---|
| ١ | `src/lib/appRoutes.ts` | إضافة `'admin'` إلى `AppRoute` وإلى `ROUTES`. **لا يُضاف إلى `MAIN_TABS`** — ليس تبويبًا للمستخدم. |
| ٢ | `src/App.tsx` | فرع عرض للمسار `admin` يرسم `<AdminShell …/>`، **خارج قشرة الجوّال** (`MobileShell`): اللوحة سطح مكتب أولًا وشريط التبويبات السفلي لا يخصّها. |
| ٣ | مضيف صغير | مكوّن يحمل الحالة: يستدعي `resolveAdminRole(session)` و`loadExecutiveSnapshot()`، ويمرّرهما للقشرة. |

**عقد المضيف** — مسمّى كي لا يُعاد اختراعه:

```tsx
import { AdminShell, resolveAdminRole, loadExecutiveSnapshot } from '@/admin'

// القرار من الجلسة الحيّة، واللقطة من حدّ المصدر. لا شيء غيرهما.
const decision = resolveAdminRole(session)          // session من useAuth()
const snapshot = await loadExecutiveSnapshot()      // اليوم: كله غير متاح
```

### ٢ج) ما **لا** يُفعل عند الوصل

- **لا يُضاف مدخل مرئي للمستخدم العادي.** اللوحة تُفتح بالعنوان المباشر، ولا
  تظهر في أي قائمة تنقّل. مدخل مرئي يخبر كل مستخدم أن اللوحة موجودة.
- **لا يُوسَّع نطاق المزامنة ولا تُلمس الموافقات** لإحضار أرقام نشاط. تلك
  المقاييس `IMPOSSIBLE_WITHOUT_CONSENT_CHANGE` **بقرار منتج**، لا بنقص هندسي.
- **لا تُضاف أفعال مدمّرة.** لا قدرة خادم مُراجَعة ⇒ لا زرّ. غير المتاح
  **خارطة طريق** لا زرّ يكذب.

## ٣. ما يحجب ماذا — جدول الاعتماديات

| البند | يحجبه | من يفكّه |
|---|---|---|
| وصل القشرة | هبوط الرأس النهائي لسباق الويب السيادي | المنسّق |
| أي رقم مستخدم | غياب دور المسؤول + غياب مسار قراءة | Backend |
| كل مقاييس الاستحقاق | **غياب نظام المصدر كلّه** (لا جدول) | Backend |
| مقاييس نشاط المنتج | تحيّز مقام الموافقة | **قرار مؤسس** |
| إكمال التخصيص | إشارة إكمال لا تعتمد على المزامنة | **قرار مؤسس** |
| فشل التفعيل | سجلّ تدقيق مجمّع بالنافذة | Backend |

## ٤. سطور `package.json` المطلوبة

**لم يُعدَّل الملف** (§1.4/٢). المنسّق يضيف بالاتحاد:

```json
"test:admin-access-denial": "node scripts/run-admin-access-denial-proof.mjs",
"test:admin-dashboard": "node scripts/run-admin-dashboard-proof.mjs",
"test:admin-secret-leak": "node scripts/run-admin-secret-leak-proof.mjs",
```

وتُضاف الثلاثة إلى `test:gate`. **`test:admin-secret-leak` يُوضع بعد `build`
في السير** لأنه يفحص `dist/` المبنيّة إضافةً إلى المصدر؛ ويعمل بلا `dist/`
(يفحص المصدر وحده) فلا يكسر ترتيبًا قائمًا.

## ٥. ما لم يُفعل في هذه الحارة — ولماذا

| لم يُفعل | السبب |
|---|---|
| توصيل حيّ بأي مصدر بيانات | `EXTERNALLY_BLOCKED`: لا دور، ولا مسار قراءة، ولا جداول استحقاق. |
| أي تعديل على `supabase/**` | خارج صلاحية الحارة صراحةً. الاحتياج موصوف أعلاه ليُنفَّذ في موضعه. |
| أي فعل كتابة أو حذف من اللوحة | لا قدرة خادم مُراجَعة ⇒ لا زرّ. |
| عرض بيانات صحّية | مستبعَد بنيويًا من النوع، ومعلَن في الشاشة، ومحروس بإثبات. |
| مدخل تنقّل مرئي | يكشف وجود اللوحة لكل مستخدم بلا داعٍ. |
