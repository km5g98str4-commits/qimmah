# مواصفة إنتاج صور التمارين الناقصة — Qimmah

**التاريخ:** 2026-08-14 · **الفرع:** `codex/qimmah-exercise-production-001` · **الأساس التاريخي:** `1bcf7a9` · **الحالي:** `d83add2`

> **حالة التنفيذ: لم تُنتَج أي صورة في هذه الموجة.**
> **الوكيل المنفِّذ لا يملك أداة توليد صور من أي نوع** — لا نصّ-إلى-صورة ولا تحرير صور.
> فُحصت الأدوات المتاحة صراحةً قبل كتابة هذا السطر. ما هو موجود يلتقط لقطات شاشة أو يرفع
> ملفًا قائمًا؛ ولا شيء منها ينتج صورة جديدة. المهارتان `canvas-design` و`algorithmic-art`
> ترسمان بالكود (p5.js / PDF) وهو **لا يصلح لتشريح بشري واقعي**.
>
> لذلك تُسلَّم هذه الموجة **قائمة الفجوة الحقيقية + هذه المواصفة + مِشْبَك المراجعة**،
> ليكون الإنتاج **أمرًا واحدًا** حين تتوفّر الأداة أو المصوِّر. **ولا يُدّعى إنتاج لم يحدث.**

## ٢. المعيار البصري

### ٢-١ الشكل المطلوب — زوج بداية/نهاية

النمط المعتمد **قائم أصلًا** في المستودع: `public/exercise-images/<slug>/0.jpg` (بداية) و`1.jpg` (نهاية).
الأصول الجديدة **تتبع النمط نفسه حرفيًا** فلا يحتاج أي كود تعديلًا.

| الخاصية | القيمة الملزمة |
|---|---|
| المسار | `public/exercise-images/<exercise-id>/0.jpg` و`1.jpg` |
| المعرّف | **المعرّف القانوني** من `src/data/exercises.ts` — لا اسم بشري ولا معرّف قديم |
| النسبة | مربّع 1:1 (يقصّه العرض إلى `object-cover`) |
| المقاس | **≥ 800×800** ليبقى حادًّا على شاشة ×3، و**≤ 180KB** للملف الواحد |
| الصيغة | JPEG جودة 82–88 (النمط الحالي)، أو WebP إن اعتُمد تحويل الأصول كلها معًا |
| الخلفية | **محايدة موحّدة** عبر الـ٣٧ كلها — رمادي فاتح مسطّح أو استوديو بلا عناصر |
| القصّ | **متّسق**: الجسم كامل داخل الإطار مع هامش ~8٪، والحركة في وسط الكادر |

### ٢-٢ ما يجعل الصورة صحيحة

1. **تشريح واقعي.** نسب بشرية سليمة. **لا زوايا مفصلية مستحيلة** — ركبة لا تنثني للخلف،
   كتف لا يدور خارج مداه، عمود فقري لا ينكسر.
2. **الحركة واضحة من الإطارين.** الفرق بين `0.jpg` و`1.jpg` يجب أن **يقرأ كحركة**:
   في السكوات = واقف ↔ في القاع؛ في الضغط = ممدود ↔ منخفض. إطاران متشابهان = فشل.
3. **المعدّة صحيحة ومطابقة للبيانات.** `equipment` في الكتالوج **ملزِم**:
   `landmine-press` فيه بار في مفصلة لاندماين، لا دمبل. `battle-ropes` فيه حبلان ثقيلان، لا حبل نطّ.
4. **بلا أي علامة تجارية.** لا شعار على جهاز أو ملابس أو أرضية، ولا اسم نادٍ، ولا علامة مائية.
   *(هذا ما أسقط أصول WorkoutX سابقًا — الميثاق §8 قرار ٨.)*
5. **ملابس محتشمة مناسبة للسوق السعودي/الخليجي.** تغطية كاملة للجذع، سروال رياضي طويل أو
   إلى الركبة. **هذا شرط منتج لا تفضيل.**
6. **إضاءة وأسلوب موحّدان** عبر الـ٣٧ كلها. الشبكة تعرضها متجاورة، فالتنافر يظهر فورًا.
7. **قابلية القراءة على الجوال.** الحركة يجب أن تُفهم في مربّع **160×160 بكسل** — وهو المقاس
   الفعلي لبطاقة المكتبة. اختبرها مصغَّرة، لا بالحجم الكامل.

### ٢-٣ حالتان لا تُنتَجان بشرًا

- **بطاقات الأجهزة** (`chest-press-machine`, `incline-chest-press-machine`, وأي جهاز قادم):
  تُنتَج **رسمًا متجهيًا داخليًا** عبر `scripts/media/build-machine-placeholders.mjs` القائم،
  لا صورة فوتوغرافية. القاعدة المستقرّة: **بطاقة الجهاز تعرض الجهاز نفسه أو البديل الأنيق.**
- **`outdoor-walk`**: مشي في الهواء الطلق. صورة عامّة لشخص يمشي **مقبولة** بشرط الخلفية المحايدة
  والملابس المحتشمة، أو **تُترك MISSING بصدق** — وهو خيار مشروع لا نقص.

## ٣. الحقوق — الشرط غير القابل للتفاوض

> **كل أصل جديد يدخل `scripts/media/provenance-manifest.json` بصفّ صريح قبل أن يُشحن.**
> `npm run test:media-rights` **يفشل** على أي مرجع بلا صفّ، أو بمضيف أصل غير موثوق،
> أو بـmagic bytes خاطئة، أو بأي حكم `UNKNOWN`/`RESTRICTED`.

الحكم المسموح لأصل جديد **واحد من اثنين فقط**:

| الحكم | متى | ما يجب توثيقه |
|---|---|---|
| `IN-HOUSE` | إنتاج قِمّة الأصلي — تصوير مكلَّف، أو رسم متجهي، أو توليد بأداة تمنح حقوقًا تجارية كاملة | الأداة/المصوِّر · التاريخ · تأكيد الحقوق التجارية · SHA-256 |
| `CLEARLY-LICENSED` | مصدر عام برخصة تسمح إعادة التوزيع التجاري (Unlicense/CC0/ملك عام) | رابط الأصل · نصّ الرخصة · SHA-256 |

**ممنوع منعًا باتًا:** أصل بحقوق مجهولة · لقطة من فيديو يوتيوب · صورة من نتائج بحث الصور ·
أصل من تطبيق منافس · أي شيء يحمل علامة مائية.

> ⚠️ **إن استُخدم مولّد صور بالذكاء الاصطناعي:** تُوثَّق **شروط خدمة المولّد وقت التوليد**
> صراحةً في صفّ الحقوق، لأن ملكية المخرجات وحقّ الاستخدام التجاري **يختلفان بين المزوّدين
> ويتغيّران بالوقت**. «ولّدها ذكاء اصطناعي» **ليست** شهادة ترخيص.

## ٤. مِشْبَك المراجعة — كل أصل يمرّ بحكم قبل أن يصل مستخدمًا

**لا أصل يُشحن بحالة معتمدة لمجرّد وجوده على القرص.** المسار:

```
إنتاج ← public/exercise-images/<id>/{0,1}.jpg
      ← صفّ حقوق في scripts/media/provenance-manifest.json
      ← npm run build:media                     # يلتقط المقاسات الحقيقية من الملفات
      ← npm run build:exercise-production-manifest
      ← npm run test:media-rights               # الحقوق
      ← npm run test:exercise-production        # التغطية والصدق
      ← مراجعة بصرية بشرية  →  APPROVED
```

**المراجعة البصرية بشرية ولا تُؤتمَت.** الفحص الآلي يثبت أن الملف موجود ومرخَّص وبالمقاس —
**ولا يثبت أن الصورة تُظهر التمرين الصحيح.** أخطر عيب في هذا المجال (نسبة صورة لتمرين آخر)
**لا يلتقطه إلا عين**. هذا بالضبط ما حدث في `chest-press-machine`: ملف سليم، مقاس سليم،
ترخيص سليم — **وجهاز خاطئ**.

**قائمة الفحص البشري لكل أصل:** الحركة صحيحة؟ · المعدّة مطابقة لـ`equipment`؟ · الإطاران
يقرآن كحركة؟ · بلا علامة تجارية؟ · الملابس مناسبة؟ · مفهومة في 160×160؟

**أي شكّ ⇒ `NEEDS_REVIEW`، ولا تصل المستخدم.** طبقة القراءة
(`src/lib/exerciseProductionMedia.ts`) تحجب كل ما ليس `APPROVED` بنيويًا، ويحرس ذلك تأكيد مضادّ.

## ٥. أمر التشغيل حين تتوفّر الأداة

```bash
# ١) أنتج الـ٣٧ زوجًا في public/exercise-images/<id>/{0,1}.jpg
#    القائمة الحيّة: PRODUCTION_IMAGE_GAP_IDS
node -e "const m=require('./src/data/exerciseProductionManifest.generated.ts')" # أو من metadata-audit.json

# ٢) سجّل الحقوق لكل أصل في scripts/media/provenance-manifest.json

# ٣) أعد بناء الطبقات ثم احكم
npm run build:media
npm run build:exercise-production-manifest
npm run test:media-rights
npm run test:exercise-production
```

**الفجوة تُقفل حين يصير `PRODUCTION_IMAGE_MISSING === 0`** — والعدّاد يُحدَّث نفسه في كل بناء،
فلا يحتاج أحد أن يتذكّر رقمًا.
