## ما يجب أن يعرفه المؤسس قبل أن يحكم

1. **الذيل الطويل للطعام غير مرفوع (F-2).** `public/food/` يحمل الطقم الساخن (٥٩٩ صنفًا)
   والبيان (٤١ شريحة موصوفة ببصماتها)، **والشرائح نفسها (~٧٠ ميغابايت) ليست في git**
   وليست مرفوعة. خطّ البيانات **جاهز**؛ التسليم الساكن **ليس**. أمر التوليد:
   `npm run food:build && npm run food:emit` ثم رفع `shards/` بجوار `hot-set.json`.
2. **رابط الشراء يذهب لجذر المتجر** `https://salla.sa/Qimmahsa` لا لصفحة المنتج.
   الكود يقرأه من `VITE_CHECKOUT_URL` — أي أنه **متغيّر نشر لا عيب كود**. ولم أضع
   معرّف منتج لا أستطيع التحقّق منه: رابط ٤٠٤ أسوأ من جذر صادق.
3. **لوحة الإدارة تعلن «غير متاح».** سلطة الأدمن تُقرأ من `app_metadata` (يكتبه الخادم)
   و**تُرفض صراحةً** أي دعوى دور في `user_metadata` بوصفها `forged-claim`. لا أصفار
   مختلقة ولا وضع مؤسس أمامي.

## المعاينة

سير CI **لا يحمل خطوة نشر**، وCloudflare Pages ينشر من `main` تلقائيًا — فدفع هذا
الفرع **ليس نشرًا**. لإنشاء معاينة:

```bash
git fetch origin codex/qimmah-final-release-convergence-001
git checkout codex/qimmah-final-release-convergence-001
npm ci && npm run build     # المخرج في dist/
```

أو من لوحة Cloudflare Pages: انشر فرع المعاينة هذا على نطاق فرعي.
`BUILD_LABEL` في الفوتر/الـconsole يعرض هاش الالتزام — **طابق قبل أن تحكم**.
