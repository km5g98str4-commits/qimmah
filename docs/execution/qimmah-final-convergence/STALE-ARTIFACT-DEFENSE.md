# دفاع الأرتيفكت البائت — §15

## الثغرة كما كانت

`scripts/release/run-release-convergence.mjs --skip-build` كان جسده كلّه:

```js
} else {
  console.log('\n▶ --skip-build: reusing existing dist-release/ artifacts')
}
```

ثم يختم سجلّ الأدلّة بـ`head: HEAD` — أي **رأس git الحالي لحظة التشغيل**.

النتيجة الحرفية: `dist-release/` مبنيّ على SHA قديم + تشغيل اليوم = تقرير يقول
«هذه نتيجة الرأس الحالي» وهو يقيس شيئًا آخر. وهذا نصّ ما يحرّمه §15، وهو نمط
سبق أن خدع هذا المشروع أكثر من مرّة.

ثغرة ثانية في نفس السجلّ: `provisional: true` كان **مثبَّتًا** مع سبب نصّي بائت
(«Web Sovereign run had not landed its final HEAD») — فكل تشغيل، مهما كان كاملًا،
يُختم «مبدئيًا». حقل يقول الشيء نفسه دائمًا لا يحمل معلومة.

## ما صار

**بصمة تُكتب مع كل بناء** — `.qimmah-build-stamp.json` داخل الأرتيفكت:
`{ mode, head, builtAt, sourceFingerprint }`.
و`sourceFingerprint` = أحدث زمن تعديل عبر `src/` · `public/` · `index.html` ·
`vite.config.ts` · `package.json` · `tailwind.config.js` — فيكشف **تعديلًا غير
ملتزَم بعد البناء**، وهو ما لا يكشفه هاش الرأس وحده.

**`verifyArtifact(mode)`** ترمي `STALE_ARTIFACT_REFUSED` بفحص مسمّى عند:

| الحالة | الرسالة تسمّي |
|---|---|
| لا `index.html` | الأرتيفكت غير مبني |
| لا بصمة | الملف المفقود بالاسم (أرتيفكت يسبق التبصيم) |
| رأس مختلف | **الرأسين معًا** — المبني والحالي |
| مصدر أحدث من البناء | أن السبب تغيّر المصدر، بالرقمين |

`--skip-build` صار يستدعيها لكل أرتيفكت مطلوب ويطبع الرأس المطابَق.
و`provisional` صار **محسوبًا**: تخفيض محرّك أو تشغيل جزئي (`--only`)، وإلا `false`.
وأُضيف `artifactsReused` صراحةً.

## الإثبات — ومهاجمته

`npm run test:artifact-freshness` · **١٠ فحوص · ٥ محاكاة التفاف** · مربوط في `test:gate`.
يعمل على طقم معزول (`dist-release/__freshness_proof`) فلا يلمس أرتيفكتًا حقيقيًا.

والإثبات نفسه **هوجم** (الميثاق §4.2 — لا يُقبل إحكام لم يُهاجَم):

```
تعطيل فحص الرأس  ⇒  ❌ ٢ فشل من ١٠ · خروج 1   ← عند التأكيدين المسمّيين بالضبط
استعادة الفحص    ⇒  ✅ ١٠ فحوص · ٠ فشل · خروج 0
```

ويحوي تأكيدين مضادّين يمنعان رخاوته: دالّة متساهلة لا تُرضي شرط السقوط، و**استثناء
تقني (`TypeError`) لا يُقبل بديلًا عن الفحص المسمّى** — فلا يمرّ الإثبات بسقوط عابر.

## ما يحمله كل ملف دليل الآن

`head` · `headSubject` · `ranAt` · `builds` (بصمة كل أرتيفكت) · `engines` (بأرقام
إصداراتها) · `validationDowngrades` · `artifactsReused` · `provisional` محسوبًا · `totals` · `suites`.
