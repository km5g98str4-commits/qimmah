# بوابة المالك والقانوني قبل الإطلاق

هذه القائمة لا تدّعي امتثالًا قانونيًا. النص المعروض في التطبيق مسودة تقنية صادقة
تحتاج مدخلات المالك ومراجعة قانونية مستقلة قبل بناء فرع الإنتاج.

## CODE-CLOSED

- [x] مصدر قانوني عربي/إنجليزي واحد: `src/legal/canonicalLegalContent.ts`.
- [x] الخصوصية والشروط والتسجيل والموافقة الصحية والفوتر تشير إلى المسارات القانونية نفسها.
- [x] حقائق المنتج: حد 12، سياسة دون 18، المعاينة المجانية، تجربة 72 ساعة، Premium بسعر 19.99 ريال، والكود المحدود.
- [x] فرع Cloudflare `main` يفشل في البناء إن بقي حقل قانوني أو اعتماد مراجعة ناقصًا.
- [x] النسخ الثابتة القديمة لا تحمل سياسة ثانية؛ تحيل إلى المسار المعتمد.

## FOUNDER_INPUT_REQUIRED

- [ ] `VITE_LEGAL_CONTROLLER_NAME_AR`: الاسم القانوني العربي للمسؤول/مقدم الخدمة.
- [ ] `VITE_LEGAL_CONTROLLER_NAME_EN`: الاسم القانوني الإنجليزي.
- [ ] `VITE_LEGAL_CONTACT_EMAIL`: بريد طلبات الخصوصية والدعم القانوني المعتمد.
- [ ] `VITE_LEGAL_EFFECTIVE_DATE`: تاريخ نفاذ النسخة المعتمدة.
- [ ] تأكيد أن 19.99 ريال هو السعر النهائي في كل قناة معتمدة.

## LEGAL_REVIEW_REQUIRED

- [ ] اعتماد صياغة الخصوصية والشروط وحذف الحساب والاحتفاظ والنقل عبر الحدود.
- [ ] اعتماد أهلية الأعمار 12–17 وغياب مسار موافقة ولي الأمر في V1.
- [ ] اعتماد حدود المسؤولية وشروط التعليق/الإنهاء والاسترداد.
- [ ] `VITE_LEGAL_GOVERNING_VENUE_AR` و`VITE_LEGAL_GOVERNING_VENUE_EN` بالنص المعتمد.
- [ ] `VITE_LEGAL_REVIEW_ID`: مرجع المراجعة/نسختها.
- [ ] `VITE_LEGAL_REVIEW_APPROVED=true` بعد الاعتماد فقط.

## PLATFORM_METADATA_REQUIRED

- [ ] مطابقة App Store/متاجر المنصات للفئة العمرية وسياسة الخصوصية.
      ⚠️ **بند تسوية خارجي مفتوح:** أهلية المنتج صارت **١٢** بينما Apple ألغت نطاق
      «+12» في ٢٠٢٥ (النطاقات: 4+ · 9+ · 13+ · 16+ · 18+ — `docs/appstore/03-age-rating.md`).
      التسوية تخصّ **بيانات المتجر لا الشيفرة**، ولم تُمسّ في هذه الموجة.
- [ ] مطابقة ملصقات الخصوصية للبيانات الفعلية والمزامنة الاختيارية والمشتريات.
- [ ] إدخال رابطَي الخصوصية والدعم المعتمدين في بيانات المتجر وسلة.
- [ ] مراجعة وصف الشراء: «يشمل تحديثات قِمّة — بلا اشتراك شهري» بلا وعود lifetime.

## PRODUCTION_CONFIGURATION_REQUIRED

- [ ] `VITE_LEGAL_DATA_REGION_AR` و`VITE_LEGAL_DATA_REGION_EN` مطابقان لمشروع Supabase الإنتاجي.
- [ ] ضبط جميع متغيرات `VITE_LEGAL_*` أعلاه في بيئة Cloudflare Production.
- [ ] بناء `main` يعلن `<meta name="qimmah-legal-ready" content="yes">`.
- [ ] فحص الخصوصية والشروط بالعربية والإنجليزية من رابط الإنتاج قبل إطلاق سلة.
