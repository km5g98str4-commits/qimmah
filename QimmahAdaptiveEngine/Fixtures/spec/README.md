# QAE Scenario Specifications (Phase 0.5)

34 scenario specifications per [CTO-QAE-001] §17. Format: `Contracts/schemas/scenario-spec.schema.json`.

**These are specifications, not executable goldens yet.** Expected outputs are never invented; every expectation block carries a source label:

- `CHARACTERIZED_EXISTING` — pinned to legacy-oracle behavior (with `oracleRef` file:line). Numeric goldens are machine-generated by the Phase-1 oracle harness (`goldenPending: true`); the assertions here bind *what* gets pinned.
- `PRODUCT_POLICY_APPROVED` — behavior approved in [CTO-QAE-001] or the founder-locked product decisions.
- `RESEARCH_REQUIRED` — blocked on an open EVIDENCE-REGISTER entry (referenced by `registerId`).
- `UNRESOLVED` — blocked on an open founder decision (referenced by `unresolvedId`, see the Phase 0.5 report).
- `NOT_APPLICABLE` — the block doesn't apply to this request kind.
