# قِمّة — Qimmah

**كل رحلتك الرياضية في صفحة واحدة** · *Your personal fitness journey in one page*

قِمّة صفحة/تطبيق شخصي للرياضي الفرد: تمارينك، أكلك، مكملاتك، أدويتك، قياساتك، والتزامك اليومي — كلها في مكان واحد، عربية أولاً (RTL)، تفتحها من جوالك كل يوم.

> **بدون خادم وبدون تسجيل دخول.** كل بياناتك تُحفظ في متصفحك (localStorage) على جهازك فقط.

---

## 🚀 التشغيل

```bash
npm install      # تثبيت الاعتماديات
npm run dev      # خادم التطوير (http://localhost:5173)
npm run build    # بناء نسخة الإنتاج إلى dist/
npm run preview  # معاينة نسخة الإنتاج
```
المتطلبات: Node.js 20+ · npm 10+. التقنيات: React + TypeScript + Vite + Tailwind.

---

## 🧭 التدفّق

1. **أول زيارة** → شاشة البداية (StartView): اختيار اللغة · ابدأ إعداد صفحتي · شاهد نموذج جاهز · استورد نسخة سابقة.
2. **الإعداد** (SetupView) → معالج خطوة بخطوة.
3. **إكمال الإعداد** → الصفحة الرئيسية (DashboardView) + تأكيد نجاح.
4. **النموذج** (DemoView) → لوحة تجريبية ببيانات عيّنة، **لا تغيّر بياناتك**.
5. **تعديل صفحتي** → يعيد فتح المعالج.

شريط التطبيق العلوي يبدّل بين: الرئيسية / الإعداد / النموذج + اللغة.

## ✨ مزايا v2 (مكتملة)

- **الملف الذكي + الحسابات**: BMI · BMR · TDEE · سعرات (محافظة/تنشيف/تضخيم) · بروتين/دهون/كارب · ماء · مدة تقديرية للهدف · اقتراح تقسيمة — كلها **قابلة للتعديل اليدوي**.
- **مكتبة التمارين** (81) + **11 قالب جدول** + اختيار/تعديل + روابط شرح لكل تمرين.
- **وضع التمرين**: تتبّع المجموعات/الأوزان · مؤقّت راحة · بدائل · صعوبة · سجل جلسات + آخر/أفضل وزن.
- **التغذية**: 60 مكوّنًا + 20 قالب وجبة + باني وجبات بحساب الماكروز + متابعة وجبات وماء يوميًا.
- **المكملات والأدوية**: 35 مكمّلًا + 45 صنف دواء للمتابعة + متابعة يومية. (الأدوية **للتنظيم فقط**.)
- **الالتزامات**: 35 عنصرًا + التزامات مخصّصة + متابعة يومية ونسبة إنجاز.
- **القياسات والتقدّم**: 15 نوع قياس + تسجيل سريع + آخر قياس + اتجاه بسيط + سجل.
- **كل قسم اختياري** عبر «الأقسام» في الإعداد، و**ثنائي اللغة** (عربي/إنجليزي).

## 🗂️ مفاتيح التخزين (localStorage)

| المفتاح | المحتوى |
|---|---|
| `qimmah:customization:v1` | كل إعدادات الصفحة (الهوية، الألوان، الأقسام، الملف، الأهداف، التمارين، التغذية، المكملات/الأدوية، الالتزامات، القياسات) |
| `qimmah:onboarding:v1` | حالة الإعداد الأولي (مكتمل/آخر خطوة) |
| `qimmah:prefs:v1` | اللغة |
| `qimmah:today:v1` | تتبّع تمارين اليوم |
| `qimmah:nutritionToday:v1` | وجبات اليوم + الماء |
| `qimmah:wellnessToday:v1` | مكملات/أدوية اليوم |
| `qimmah:commitmentsToday:v1` | التزامات اليوم |
| `qimmah:workoutSessions:v1` | سجل جلسات التمرين |
| `qimmah:exerciseHistory:v1` | آخر/أفضل وزن لكل تمرين |
| `qimmah:measurementLogs:v1` | سجل القياسات |

تتبّعات «اليوم» تُصفّر تلقائيًا عند تغيّر اليوم. لا شيء يُرفع لأي خادم.

## 🧪 وضع النموذج (Demo)

«شاهد نموذج جاهز» يعرض **رياضيًا تجريبيًا** كامل البيانات (ملف، أهداف، تمارين، أكل، مكملات، دواء عيّنة، التزامات، قياسات) عبر مزوّد منفصل **لا يكتب في localStorage** ولا يغيّر بيانات المستخدم.

---

## 🩺 ملاحظات السلامة

- **الحسابات تقديرية** للتنظيم والمتابعة فقط، وليست بديلًا عن مختص.
- **القيم الغذائية تقديرية** وقد تختلف حسب المنتج والتحضير.
- **الأدوية للمتابعة فقط**: لا تبدأ أو توقف أو تغيّر جرعة أي دواء بدون استشارة الطبيب أو الصيدلي. لا توصية بأي جرعة.
- **القياسات الصحية المتقدمة (ضغط/سكر) للتسجيل فقط، وليست للتشخيص.**

---

## 🚫 ما ليست قِمّة

ليست نظام إدارة نوادٍ، ولا عضويات، ولا حجوزات، ولا مدفوعات، ولا منصة SaaS لنادٍ، ولا CRM للمدربين. هي **صفحة شخصية للرياضي الفرد** فقط.

## 🛠️ التخصيص (للمطوّر)

- الهوية والألوان: مركز التخصيص (داخل التطبيق) أو `tailwind.config.js` + `src/config/`.

## ☁️ النشر (Deployment)

المشروع **Vite ثابت (SPA)** — يُبنى إلى مجلد `dist` ويعمل على أي استضافة ثابتة. لا backend.

### البناء والمعاينة محليًا
```bash
npm install
npm run build      # ⇠ ينتج dist/
npm run preview    # معاينة الإنتاج على http://localhost:4173
```

### Netlify
- ملف `netlify.toml` جاهز: `command = npm run build` · `publish = dist` · Node 20.
- **SPA fallback**: مُهيّأ عبر `netlify.toml` و`public/_redirects` (`/* → /index.html 200`).
- النشر: اربط الريبو في Netlify (يلتقط الإعدادات تلقائيًا)، أو ارفع مجلد `dist` يدويًا، أو:
  ```bash
  npx netlify-cli deploy --prod --dir=dist
  ```

### Vercel
- ملف `vercel.json` جاهز: `framework: vite` · `buildCommand: npm run build` · `outputDirectory: dist` + **rewrite** لكل المسارات إلى `index.html`.
- النشر: استورد الريبو في Vercel (يتعرّف على Vite تلقائيًا)، أو:
  ```bash
  npx vercel --prod
  ```

### ملاحظات
- **SPA fallback** ضروري: التطبيق يدير حالاته في الذاكرة (بلا React Router)، فأي تحديث صفحة على أي حالة يجب أن يخدم `index.html` (مُهيّأ للمنصّتين).
- `base` الافتراضي `/` — مناسب للنشر على جذر النطاق. لو نشرت تحت مسار فرعي، اضبط `base` في `vite.config.ts`.
- لا متغيرات بيئة مطلوبة. كل البيانات في متصفح المستخدم.

راجع `PREVIEW-CHECKLIST.md` قبل العرض.
